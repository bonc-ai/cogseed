# CogSeed Community Contributions

This directory contains community contribution candidates that are reviewed in
the public repository but are not bundled with CogSeed.

- [Community Skill pilot](./skills/README.md)
- [简体中文](./README.zh-CN.md)

An accepted contribution is imported into private development. Its public PR
stays open until the corresponding source candidate passes release gates, then
merges with its original author commits after required CI and maintainer approval.
The next public snapshot retains that history. A repository-reviewed candidate
is not evidence that the contribution is published to CogSeed Hub, bundled with a release, or
approved for production use.
