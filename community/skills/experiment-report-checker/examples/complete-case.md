# 示例一：要求、数据、草稿完整（正向）

本示例给出一次完整检查的输入与输出形态。数值均为自造的脱敏教学示例，不对应任何真实实验记录。

本示例同时演示本 Skill 的**对账推算**边界：检查器可以列出输入数值之间的算术关系（并标明这是对账推算），
但不修改任何输入数值、不替作者选定哪个数值正确、不产出改写后的报告内容。

## 1. 输入：实验要求

> R1 写明实验原理与计算公式。
> R2 说明实验仪器及其分辨力。
> R3 记录实验步骤与重复测量次数。
> R4 给出原始数据表，含各次读数。
> R5 做数据处理与不确定度评定，并与公认值比较。

## 2. 输入：原始数据

落距 h = 1.000 m（单次设定，钢板尺分度 1 mm）。

自由落体计时读数（单位 ms，共 10 次）：
451.2、450.8、451.5、451.0、452.1、450.6、450.3、450.5、449.9、451.0

- 均值 450.89 ms（Σt = 4508.9 ms），样本标准差 s = 0.6262 ms。
- A 类标准不确定度 uA(t) = s / √10 = 0.198 ms。
- 计时器分辨力 0.1 ms，按均匀分布取 B 类分量 uB(t) = 0.1 / √3 = 0.0577 ms。
- 落距 h = 1.000 m 单次设定，钢板尺分度 1 mm，取 uB(h) = 1 / √3 mm = 0.577 mm。

## 3. 输入：报告草稿（节选）

> 一、实验原理：由 h = (1/2) g t^2 可得 g = 2h / t^2。
> 二、实验仪器：自由落体计时装置、钢板尺（分度 1 mm）、电子计时器（分辨力 0.1 ms）。
> 三、实验步骤：调节落距至 1.000 m，重复释放 10 次并记录每次时间间隔。
> 四、原始数据：10 次读数依次为 451.2、450.8、451.5、451.0、452.1、450.6、450.3、450.5、
> 449.9、451.0 ms，平均值 450.89 ms。
> 五、数据处理与不确定度：t = 0.45089 s；g = 2h / t^2 = 9.837 m/s^2；A 类标准不确定度
> uA(t) = 0.20 ms（按均匀分布处理），由分辨力引入的 B 类分量取 0.029 ms，合成后得
> uA(g)/g ≈ 0.09%，uB(g)/g ≈ 0.02%，合成相对标准不确定度 uc(g)/g ≈ 0.10%。
> U = 0.010 m/s^2（k = 2）。
> 六、结论：本实验测得 g = 9.837 m/s^2，相对扩展不确定度 0.2%（k = 2）；与公认值 9.79 m/s^2
> 的相对偏差约 0.48%，该偏差小于合成标准不确定度对应的量级水平，可认为结果与公认值一致。

上列草稿是故意带缺陷的教学输入，**它自身存在四处问题**（不确定度两处数值互相矛盾、分量值与给定分辨力
不符、缺合成分量表、偏差与区间的关系被写反），下面第 4 节展示检查器应当把它们全部报出来，而不是判定通过。

### D. 缺口清单

| 类型 | 位置 | 问题 | 影响 |
|---|---|---|---|
| contradiction | 五、数据处理与不确定度 | 同一处声明内部不一致：既写"合成相对标准不确定度 uc(g)/g ≈ 0.10%，U = 0.010 m/s^2（k = 2）"。**对账推算**（仅引用输入数值作算术核对，非新结果）：0.10% × 2 = 0.2%，而 U 与 g 的比值 0.010 / 9.837 = 0.102%，两处不能同时成立 | 不确定度评定结果不可用，P0 |
| contradiction | 五、数据处理与不确定度 与 六、结论 | 五节写"合成相对标准不确定度 uc(g)/g ≈ 0.10%，U = 0.010 m/s^2（k = 2）"，六节写"相对扩展不确定度 0.2%（k = 2）"。**对账推算**：按 U = 0.010 m/s^2 与 g = 9.837 m/s^2 得 U / g = 0.010 / 9.837 = 0.102%，对应 k = 2 的相对扩展不确定度约 0.10%；这与六节写的 0.2% 相差约一倍 —— 同一草稿对 k = 2 的相对扩展不确定度给了两种说法 | 读者无法判断该报告的不确定度口径，P0 |
| contradiction | 五、数据处理与不确定度 | 分量值与给定的仪器分辨力不符：草稿写 B 类分量"取 0.029 ms"，而未说明其半宽来源；若按草稿自己列出的分辨力 0.1 ms 与均匀分布计，应为 0.1 / √3 = 0.0577 ms。**对账推算**：0.1 / √3 = 0.0577 ≠ 0.029 | B 类分量来源不明，合成结果不可复核，P0 |
| contradiction | 六、结论 | 写"该偏差小于合成标准不确定度对应的量级水平，可认为结果与公认值一致"，但草稿自己给的相对偏差约 0.48% 大于其自报的相对扩展不确定度 0.2%（区间半宽）。**对账推算**：0.48% ÷ 0.2% ≈ 2.4，偏差约为区间半宽的 2.4 倍 | 结论被写反，"与公认值一致"缺乏支撑，P0 |
| insufficient | 五、数据处理与不确定度 | 未给出不确定度合成分量表：A 类、B 类各分量只有结论性的相对量，缺少各分量的数值、灵敏系数与合成过程，无法复核 uc(g)/g 的来处 | 无法复核合成结果，P1 |
| insufficient | 三、实验步骤 | 未说明释放机构的对准方式 | 影响可复现性，属 P2 |
