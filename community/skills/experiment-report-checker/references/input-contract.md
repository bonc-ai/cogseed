# 输入契约（input contract）

本文件定义 experiment-report-checker 接受什么、拒绝什么，以及材料缺失时的降级规则。SKILL.md 的
`## 输入` 一节是本契约的摘要，两处冲突时以本文件为准。

## 1. 必需材料

| 材料 | 标识 | 说明 | 缺失后果 |
|---|---|---|---|
| 实验要求 | `requirements` | 实验目的、必做内容、评分点或任务书原文 | 停止要求覆盖表；不得自行推断要求 |
| 数据 | `data` | 原始数据，或数据摘要（汇总值、均值、标准差等） | 停止全部证据链判断与数值一致性核对 |
| 报告草稿 | `report_draft` | 待检查的报告文本 | 停止全部报告检查，只输出材料清单 |

三项必须同时具备才能执行完整检查。任一缺失时按 §4 降级，并在输出 A 节与 G 节声明停止范围。

## 2. 可选材料

| 材料 | 标识 | 启用后的作用 |
|---|---|---|
| 格式规范 | `format_spec` | 结构检查与格式类建议以该规范为准，而非通用惯例 |
| 安全要求 | `safety_requirements` | 仅用于检查报告是否遗漏必须记录的安全项；**不用于判断安全本身** |
| 课程评分标准 | `rubric` | 要求覆盖表的权重来源；用于把缺陷按分值影响排序 |

可选材料未提供时，不得假定其内容，也不得用通用标准冒充用户课程的标准。

## 3. 材料形态要求

- `requirements` 可为逐条列表或整段说明；抽取时保留原文措辞，编号 R1…Rn。
- `data` 优先接受结构化文本（表格或逐行记录）。接受数据摘要，但摘要会降低证据链判断的确定性：
  凡基于摘要得出的判断，证据强度标 `partial`，并在输出中声明判断受材料限制。
- `data` 若只有图（曲线图、频谱图等）而无可读数值，视为未提供可核对的数值数据：不得从图上估读数值。
- `report_draft` 须为可读文本。只有图片、扫描件或 PDF 时，要求用户先提供文本版本；本 Skill 不做 OCR。
- 文本编码须为 UTF-8。出现替换字符或乱码时停止并对应用户确认编码。

## 4. 缺失降级矩阵

| 缺失项 | 仍可执行 | 必须停止 |
|---|---|---|
| `requirements` | 结构检查、内部一致性检查（数值、趋势、图表引用） | 要求覆盖表；任何"报告是否满足要求"的判断 |
| `data` | 结构检查、要求覆盖到小节层级、措辞与格式类问题 | 证据链映射表的可支撑性判定、数值一致性核对、充分性检查 |
| `report_draft` | 材料清点 | 全部报告检查 |
| 三项全缺 | 无 | 全部检查；只输出所需材料清单 |

降级不是失败。降级时输出仍按 §输出契约 的七节结构给出，只是相应小节标注为"因材料缺失未执行"，
并在 F 节列出补齐材料的具体清单。

## 5. 明确拒绝的输入

- 要求修改、格式化、补全或重算数据的请求。本 Skill 只输出缺陷与建议，不产出新数据。
- 要求解读安全规程、判断实验风险等级、代替导师或安全员或伦理审查做专业判断的请求。
- 要求联网检索、对照外部数据库、引用本 Skill 看不到的材料。
- 程序代码、可执行脚本、二进制文件、数据集文件（不做代码审查，不重新跑分析）。
- 包含真实个人身份信息或未脱敏学生信息的材料。要求先脱敏。

## 6. Agent 层注入字段（本 Skill 不自填）

当本 Skill 由 Agent 层调度执行时，以下字段由 Agent 层注入，本 Skill 只读取、不填写、不修改：

| 字段 | 说明 |
|---|---|
| `task_id` | 本次任务标识，用于把输出与审计条目关联 |
| `owner_context` | 任务归属上下文（责任人、角色、授权范围） |
| `audit_refs` | 审计引用，随输出一并回传；本 Skill 不生成也不改写审计账本 |

本 Skill 不接受自行编造的 `task_id` 或 `owner_context`。缺失时正常执行，但输出中不出现这两个字段，
并在 G 节注明未由 Agent 层注入。
