# 文献综述提纲审查器

对已成文的文献综述提纲做提交前的自查：把提纲里的每个条目映射回用户自己提供的文献材料，标出哪些条目有来源支撑、哪些条目缺证据、论证顺序与覆盖范围是否与研究问题匹配，最后给出可定位、可核对的修改建议。本 Skill 只处理用户明确提供的文字内容，不检索、不补造任何文献。

use_when:
- 用户同时提供了文献材料（笔记、摘要或引用信息）和综述提纲，希望检查提纲是否有遗漏、支撑是否充分；
- 用户希望知道提纲里每个主题分别由哪些材料支撑，或哪一部分还没有证据；
- 用户希望调整综述的结构与论证顺序，想知道先讲什么、后讲什么更站得住。

do_not_use_when:
- 用户只给出综述提纲、没有提供任何文献材料——停止，列出缺失项并索取材料，不基于主题推断该领域有哪些文献，也不用记忆中的文献充当来源；
- 用户要求检索、查找、补充文献或引用——拒绝，本 Skill 不联网；
- 用户要求虚构作者、标题、刊名、年份、DOI、引用格式或研究结论，或用"先占位""随便写几条凑数"的方式补引用——拒绝；
- 用户要求把未提供的文献写成来源事实，或要求把提纲改得"看起来引用更多"——拒绝；
- 用户要求评估文献本身的数据质量、统计方法或做 meta 分析——超出范围，说明只能审查提纲与已有材料的对应关系；
- 用户要求联网、执行脚本或写入外部系统——拒绝。

## 输入

必需输入（任一缺失即停止，在输出中列出缺失项并追问，不得自行假设或补造）：

1. 文献材料：用户明确提供的文献笔记、摘要或引用信息，条目式、段落式、列表式均可；
2. 综述提纲：用户明确提供的提纲全文，含主题条目与层级关系。

可选输入（缺失时按下述默认处理，并把假设写入输出的"待确认问题"）：

- 研究问题或核心论点：缺失时按提纲标题推断，标注为"合理推断"并请用户确认；
- 范围限定（时间跨度、地域、学科、文献类型）：缺失时不做任何收紧或扩张，只提示用户确认；
- 课程或格式要求（字数、章节数、引用格式）：缺失时不假设字数上限与格式细则。

编号约定：文献材料按用户给出的顺序记为 M1、M2……，提纲条目按用户给出的顺序记为 T1、T2……；二级要点记为 T3.1 这样的层级编号。用户在原文里已有的编号一律沿用，不重新编号、不合并、不拆分用户条目。判定标准与计数规则见 references/mapping-rules.md。

## 工作流

1. 输入校验：逐项核对两个必需输入。任一缺失即停止，只输出缺失项、追问，以及"本 Skill 不联网、不代为检索或编造"的说明，不做部分分析；
2. 材料建账：把文献材料整理为 M 编号清单，逐条记录材料自身写明的可核对要素（作者、年份、标题、出处）；用户没写的要素留空并标"未提供"，不补全；
3. 提纲建账：把提纲整理为 T 编号清单（含二级要点），标注每个条目的层级与承担的功能（背景、概念界定、现状、争议、方法、结论）；
4. 逐条映射：按 references/mapping-rules.md 的判定标准，把每个 T 条目映射到 M 条目，每条只输出三种结果之一——有直接支撑 / 仅间接支撑 / 无支撑（待补证据）；
5. 缺口与顺序评估：
   - 证据缺口：无支撑的条目、只有一条来源支撑的关键条目、以及材料写明但提纲完全没覆盖的维度；
   - 论证顺序：是否先界定概念再作比较、是否把结论性内容排在证据之前、相邻主题之间是否缺过渡；
   - 范围一致性：提纲覆盖的范围与材料覆盖的范围、研究问题之间是否偏移；
6. 分级并组织输出：按 references/output-template.md 的六段结构输出，发现按 P0/P1/P2 分级，每条给出 T/M 定位与来源类型标签。

每条结论必须标注来源类型：材料事实（材料中明确写出的内容）、合理推断（由材料或提纲推出的判断）、修改建议（建议的改法），三类不得混用。无法定位到具体 T 或 M 条目的观察不写入结论。

## 输出

固定为六段结构，完整模板见 references/output-template.md：

1. 总体判断：研究问题复述、材料条目数、提纲条目数、覆盖概况、本次审查的假设声明；
2. 主题—材料映射表：T 编号、条目主题、对应 M 编号、支撑强度、判定（含"待补证据"）；
3. 逐条目评估：每个条目一段，写明已有来源支撑、支撑是否单薄、以及该条目在提纲中的作用；
4. 证据缺口与未覆盖问题：逐条列出，缺失证据的一律标记"待补证据"，并说明需要用户补充哪一类材料（不给出任何具体文献名）；
5. 结构、论证顺序与范围调整建议：P0/P1/P2 分组，每条带 T 编号定位与来源类型标签；
6. 缺失信息与待确认问题：固定结尾，列出尚未提供的输入、已做出的假设、需要用户决定的事项。

映射表的条目数与编号必须与第三段、第四段正文完全一致。任何"无支撑"的判定都要能在材料清单里指认缺席，不得凭印象给出。完整的正向示例（含 6 条材料、5 个提纲条目的完整输入与输出）见 examples/literature-review-walkthrough.md。

## 边界

- 只处理用户明确提供的文字内容，不联网、不执行脚本、不写入外部系统；
- 一律不检索、不补充、不推荐任何具体文献、作者、标题、刊名、DOI 或链接，也不引用记忆中的文献充当材料；
- 材料中未写出的要素（作者、年份、出处等）保持"未提供"，不补全、不推测、不改写；
- 覆盖判定与缺口判定必须给出 M/T 定位；无法定位的判断不输出；
- 不评估文献本身的研究质量、数据与统计方法，不做 meta 分析，不代替导师或人工审阅，输出仅供参考，不直接覆盖用户的正式提纲。
