# Feature Specification: 出身区分全链收敛（模型记的=已确定）

**Feature Branch**: `认知资产迭代`
**Created**: 2026-09-20（回填同日）
**Status**: Implemented
**Input**: 用户需求原话：「这个不只是界面，还有前、后调用后端等整条逻辑都需要做出改变」+「总之，收敛」——模型记下来的就是已确定的内容，全链不再区分是不是模型自己记的。

**Source**: 全链探索报告（出身三值 16 文件引用清单）、提交 6128c076。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 一条内容零出身标记

1. **Given** 画像页任意条目 **When** 渲染 **Then** 纯内容（无「已确认/模型记的」前缀/章）；同一件事不出现两条（存量重复已语义融合：7→6 条，相似度 0.854）。
2. **Given** 资产详情页 **When** 查看 **Then** 无出身章、无「转正」按钮（转正链全退役：IPC 透传/路由/文案/守卫）。

### User Story 2 - 主进程行为单值化

3. **Given** 任何晋升路径（人工/自动/KStar） **When** 资产落库 **Then** lifecycle 恒为 user_confirmed_unverified（=确定、未实证）；画像注入排序两档（72h 内>其余）；同步过滤不再按出身排除；给模型的元数据无「生命周期」行。
4. **Given** 升「已实证」链路 **When** 使用回执/效果证明达标 **Then** 照常升档（成熟度轴与出身完全解耦，不受收敛影响）。

### User Story 3 - 存量清扫

5. **Given** 真机 personal 生效资产含语义重复对 **When** 诊断清扫（备份先行） **Then** 短条并入详细条（版本管线），画像页单条呈现。

## 非目标

- lifecycleStatus 三值类型与存量盘上数据保留（读旧兼容）——彻底删枚举涉及数据迁移，收益低风险高。
- 认知树阶段命名（growing=已确认）属映射层另一条线。
