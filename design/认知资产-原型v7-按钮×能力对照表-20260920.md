## 表 B · 从原型里删掉的（产品没有对应能力，留着就是假按钮）

| 删掉的 | 为什么删 |
|---|---|
| 顶部搜索框「搜索记住的内容…」 | 产品没有资产搜索：无 `recall.assets.search` 通道，`search.global` 也不覆盖资产；用户故事里也没有搜索（只有「一屏一列每条一句话」） |
| 底部「记忆 —— AI 自动记住对话中的信息」开关 | 「记忆」作为独立概念已退役（09-17 口径）；它的实际功能就是「沉淀设置·整理功能」开关，同一件事不做两个入口（子安 09-20 原话：看不懂、没用、没意义） |
| 底部「导出」「导入」两个按钮 | 位置错（产品在个人本体页）→ 移进「个人本体」抽屉，名字去掉「记忆」（导出/导入） |
| 树页右下「等你处理 N」卡 | 与根部那个光斑是同一件事，重复入口 |
| 树页右上「查看 N 条待确认候选」按钮 | 同上，根部光斑已经是入口（子安 09-20：树上就是按钮） |

| 候选详情「保存并使用」文案 | 与规则「保存≠使用授权」冲突（09-15 缺口核对点名），改为「保存」 |
| 重复/死代码：第二个 `onQ`、第一个 `spotSvg`、`candSetCat()`、`candChoice`、`about` 数组 | 合并残留，留着就是两个定义打架 |

## 表 D · 原型简化处（照实标注，不是产品行为）
