## 视觉对齐返工 · 全量原型移植(2026-09-21)

**背景**: Phase 3-10 交付后真机走查发现——五页签的**视觉**与 HTML 原型差距大（当时只对齐了信息架构与交互契约，没有搬视觉）。子安给了最后通牒式期限：要么这次彻底对齐，要么从动前端之前重新分支。于是按「原型 CSS 逐条搬运 + 标记逐页替换」重做了一遍视觉层。

### 做法（三条机械规则）

1. **统一加 `#ca-root` 前缀**: 原型类名（`.card`/`.row`/`.tag`/`.btn`…）是页面级通用名，与应用全局样式同名，作用域限定才能互不污染。
2. **颜色/圆角/字号/层级全部改引 tokens.css 变量**（同值或 Δ 不可辨的近值）——`scripts/check-design-tokens.mjs` 对字面量零容忍，本文件回到 0 新增。
3. **原型外壳不搬**: `.shell/.dock/.tabs/.ovl/.toast/.mod` 由应用壳层与共享组件承担；页面高度从 `calc(100vh - 46px)` 改为撑满容器。

层序不用 z-index: `.fl-top/.fl-bottom/.drawer/.tip` 都是定位元素，按 DOM 顺序压层（与原型 z-index 5/20/60 同序）。守护测试冻结了本文件的 z-index 声明数（=1），这条不能破。

- **树关系白名单漏 `same_family`**（`src/main/features/recall/tree-service.ts`）: 该文件的 `RELATION_KINDS` 是 `asset-relations.ts` 的白名单副本，判族引擎写的 `same_family` 没同步进来 → 任何带同族关系的资产都会让整棵树读取抛 `malformed cognition tree asset relation contract`，面板顶部常驻「部分数据读取失败」。**真机抓出，已补全**。（86 个 better-sqlite3 原生模块加载失败是环境问题，与本条无关。）
- **族名腰斩**: 组名兜底原是 `title.slice(0,10)`，把「沟通风格偏好（2026-09-19 明确提出）：…」切成「沟通风格偏好（2026」——括号/日期被腰斩。改成先取自然头段（到冒号/括号/间隔号为止）再截断。
- **按钮皮肤被静默覆盖**: 旧的 `.ca-app .ui-button.ca-backlink` 变体（3 类选择器）打不过新移植的 `#ca-root .btn`（ID 级），返回链接变成了绿实心按钮；旧变体块随标记迁移一并删除。

### 整理详情：滚动跳顶 + 卡片无内边距（2026-09-21 深夜，发版前真机修复）

子安真机报「详情页显示混乱 + 往下翻会跳回最上面」。CDP 实测（scrollTop 600 → 渲染后 0、`#ca-scroll` 元素被替换）定位到根因：

1. **持久页签壳从未真正持久**：壳的第三个节点标记写的是 `class="ca-banner-slot"`（**没有 id**），而 render 的分支判定用 `getElementById('ca-banner-slot')` → 恒为 null → **每次渲染都走整壳重建分支**。后果不止滚动归零——4s 轮询、每次数据刷新都整页重建（tab 焦点、本体挂载点持久化全被绕过，纯靠焦点恢复逻辑兜着）。修复：补 `id="ca-banner-slot"`（一字符级），真机复测 `elementReplaced=false`、scrollTop 600 保持不动。
2. **卡片无内边距**：原型的 `.card` 本身不带 padding（原型在标记里逐卡 inline），移植时没搬这层 → 详情页所有卡片文字贴边（「显示混乱」的直接观感）。修复：`#ca-root .card` 给默认 `padding: 14px 16px`，自带内边距的复合卡（selection-card 等）按源序覆盖。

## 已知限制

- **`.ca-*` 遗留件已清**: 移植后无引用的 72 条旧规则（`.ca-card`/`.ca-row`/`.ca-note`/…）已随标记迁移删除，`cognition-assets.css` 77K→69K；`ca-*` 前缀现在只留给原型没有的自建复合件（时间线、沉淀卡、版本展开块、整理五步条…）。
- **窄窗树形**: 枝长按可用半宽收敛（`Math.max(200, W/2 - 96)`）——桌面宽度（≥1000px 内容区）与原型几何逐像素一致，更窄才缩短，避免枝牌顶出画布。原型本身没有窄窗几何，这是移植时补的。
- **后端测试的 86 个失败与本轮无关**: `better-sqlite3` 原生绑定 `ERR_DLOPEN_FAILED`（Node/Electron ABI 不匹配的环境问题），集中在 `test/main/**` 的 kb/contexts/library 等域；renderer 侧 221 文件 / 2424 测试全绿。
- **原型侧栏的 3 张统计磁贴未复刻到本体页**: 本体页左栏的三盒导航行已带计数（词汇/事实/规则），再加统计磁贴是同一组数字的第二份副本——按「一个事实一份呈现」省略。
