# 能力页对齐说明

范围：K02 智能体一级列表、技能、资料库及能力页签精简。用户指定将「触点」显示为 `IM`；移除设计稿的插件和模型与额度页签及专属页面。全局设置模型配置、输入台执行配置保持独立，不随页签删除。原始差异事实见 [页面差异记录](PageComparison-2026-09-05.md)，本文记录后续实施。

## 页面与共享层

- `CapabilitiesScreen.jsx`：五个语义入口 `agents/tools/skills/library/im`。历史数字 `0/1/3/4/5` 保留原含义，`2/6` 返回智能体并提示入口已调整，避免删页后数组索引指向错误页面。
- 智能体：AI 团队标题/说明，主智能体、外接、自定义、平台分组，分类、简介、版本、交付与技能统计；名称打开管理工作台，主动作使用智能体进入草稿。
- `AgentCreateDialog.jsx`：首页和能力列表共用创建/外接弹窗，复用共享 Dialog、Tabs、Field、Input、Select、Textarea；名称/简介校验。创建项写入 `window.CapabilityAgentStore`，页面跳转后仍可管理。
- [技能说明](CapabilitySkills.md)：独立业务组合，复用共享资源卡片、分类、表单和对话框。
- [资料库说明](CapabilityLibrary.md)：文件树、新建、行内重命名、编辑、保存与删除确认。
- [共享市场](CapabilityMarketplace.md)：智能体/技能的「更多」共用市场列表与详情，避免分别复制市场交互。

## 数据与运行边界

数据为金融业务示例，数量来自示例本身，不复制安装版的个人文件、智能体或账号数据。各模块仅保留当前页面会话内变动，整页刷新重置。创建智能体不调用真实模型生成流程；外接仅新增未启用配置，不启动本机 CLI/网关。技能安装、导入、扫描及 MCP 连接不伪造真实服务成功。资料文件只处理用户主动选择的 File；不访问客户端资料目录或知识库索引。

`IM` 只改页签名称，原消息渠道预览交互继续保留，其关联按钮仍是旧版示例状态；本次不声称完成真实渠道接入。正式 Renderer、IPC 和用户数据未修改。

## 本轮核验

安装版实见：Agent 一级分组、创建/外接弹窗、更多进入市场；资料库标题、搜索、文件计数及「新建文本 / 新建文件夹 / 添加文件」菜单。仅打开/取消参考 UI，没有创建安装版记录。

浏览器在本地 HTTP 预览实测：五页签、创建必填错误、模态内选择器、Escape 先关选择器、创建后进入编辑、跨页签保留智能体；技能安检详情及阻断使用；资料库初始未选中、新建、Enter 改名、编辑与 Cmd+S；共享市场入口。发现并修正从市场跳首页残留参数遮挡创建详情的问题，统一构建及最终复测结果由 [验收记录](../../verification.md) 维护。
