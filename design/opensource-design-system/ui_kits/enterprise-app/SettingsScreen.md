# 设置页面样例

沿用独立设置页、紧凑内容列、返回应用及共享设计组件。设置包含数据、账号、账号与用量、通用、安全与信任、关于我们六项。按当前设计要求移除配置页、模型授权与添加入口。

目录统一使用 [设置](index.html?page=settings) 一个入口；六项内容通过左侧菜单切换。

## 菜单与源码对照

| 菜单 | 预览内容 | 源码依据 |
| --- | --- | --- |
| 数据 | 记忆管理、导入输入/审核/分区合并、导出内容；资料库跳转；回收站列表、恢复、彻底删除确认与空态 | `src/renderer/index.html` data pane；`modules/memory.js` |
| 账号 | 登录/未登录状态、管理按钮滚动到设备、设备撤销、退出确认；三步注销演示、示例身份验证及最终确认 | `modules/hub-account.js` |
| 账号与用量 | 仅展示额度占位 | `src/renderer/index.html` usage pane；`settings.js::_settingsBindUsageConnectionsOnce` |
| 通用 | 语言、自动/关闭/低/高推理强度、任务通知与系统设置入口、谨慎/常规/信任权限、自进化开关 | `src/renderer/index.html` general pane；`modules/settings.js` |
| 安全与信任 | 只读组件状态、记录与评分、重新检查、搜索单技能、刷新和示例 JSON 回执导出 | `modules/settings-security.js` |
| 关于我们 | 检查更新、官网版本介绍链接、模拟下载进度、跳过版本、安装包和重启安装入口 | `src/renderer/index.html` about pane |

源码路径相对于 `src/renderer/`，`features/tts_auth.ts` 相对于 `src/main/`。顶层设置路由默认进入数据；未知 section 回退数据；菜单切换同步 URL，刷新与前进后退可恢复菜单。返回应用恢复来源页，独立打开则返回首页。记忆详情保持为数据下的嵌套页面，可通过 [记忆管理](index.html?page=settings&section=data&detail=memory) 直达，返回和浏览器历史同步 URL。资料库复用 [能力页资料库](index.html?page=capabilities&tab=4)，支持刷新保留分类。

## 分组样式

全部设置菜单复用共享 SettingsSection；所有模块统一采用浅边框分组，不再区分样式变体。标题下移除横线，组间距统一为 32px，行内密度保持紧凑。组件定义与独立预览见 [设置分组](../../components/forms/SettingsSection.prompt.md)。

## 交互与边界

- 六个页面始终共用 SettingsScreen / SettingsRow / SettingsSection 和设计系统控件。切换菜单保留 React 内存状态；刷新、离开设置或关闭页面后重置，不写本地存储，不调用 IPC；只有点击官网版本介绍会打开外部网页。
- 服务商、模型、设备、授权和检查记录均为代表性示例；不声称对应真实账号或实时服务商目录。API Key 输入仅参与本次预览，勿填真实密钥。
- 模型和服务商编辑、优先级排序、增删确认、权限与通知切换会更新预览状态。OAuth、账号登录、验证码、连接测试、安全扫描与更新下载是明确标识的模拟流程。
- 回执导出生成包含 `preview: true` 的本地 JSON 示例文件。记忆导入支持粘贴和读取用户选择的文本文件，在页面内按行演示解析、逐条勾选、选择偏好/共享分区、合并去重；不执行模型解析或安全扫描。导出展示两类内容、复制及文件定位反馈，剪贴板失败保留手动复制路径。
- 资料库跳转复用能力页；账号管理与源码一致，滚动到当前账号的设备列表，不新增账号子页。版本介绍链接沿用源码官网地址，不编造发布说明。数据目录、系统通知设置、记忆文件定位和安装动作属于系统入口，仅保留反馈。
- 自定义服务商的获取模型列表补充候选勾选、已添加禁用、取消和导入选择，仍为预览目录。通用、用量和安全模块未发现其他独立下级页面，保留已有表单、技能选择与回执导出。
- 用量仍是源码占位，无虚构额度、扣费或权益。注销不杜撰服务端反悔期，不删除真实账号或本机数据。
- 非正常状态（真实授权损坏修复、网络异常、更新校验失败、设备与授权加载失败）不在当前模拟服务覆盖范围内；正式接入仍须遵循对应源码状态与恢复契约。
