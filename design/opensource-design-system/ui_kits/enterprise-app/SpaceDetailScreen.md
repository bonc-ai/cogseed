# 工作空间详情

稳定入口：[工作空间详情](index.html?page=space&space=space-0)。`view=tasks|artifacts|assets` 保留当前视图；`page=space-task` 与 `space`、`task` 参数保持任务返回上下文。卡片标题进入工作台；「继续工作」接续最近任务（无任务时创建新任务），空空间也可进入；任务详情复用单个 TaskScreen，独立 task.html 的状态画板保留。
