# 资料库组合契约

`CapabilityLibrary.jsx` 提供 `window.CapabilityLibrary({ onSearch, onUse })`。由能力页装载；默认未选择文件。此文件负责资料库专属文件树、文件预览和会话内文件操作；所有按钮、字段、选择器、菜单、确认与空态复用共享组件，无公共 token / 基础组件变更。

- `onSearch()`：打开统一全局搜索。接入方须提供回调，不另建资料库搜索浮层。
- `onUse({ name, text, reference })`：请求首页草稿引用文件，不执行模型调用或发送消息。`text` 为文件文本（不支持读取时为空）。
- 模块生命周期内保留新建、上传、重命名、编辑、删除与移动；切换能力页签后保留，整页刷新重置。文件夹展开状态与文件选择分开，默认文件数为 3。

## 来源与行为

参考 `src/renderer/modules/contexts.js` 中 `_ctxMenuItemsFor`、`renameCtxEntry`、`createCtxNewTextFile` 和文本编辑器。根菜单提供新建文本、新建文件夹和添加文件；行内命名支持 Enter 提交、Escape 取消、输入法保护，验证空名称、路径符号与同目录重名。新建文本立即产生空文件并选中，取消命名保留文件。文件夹删除递归移除内容且先确认。文件编辑保存更新正文，取消编辑恢复原文；切换文件前确认放弃未保存修改。

文件/文件夹整理支持当前资料库内部移动，排除自身及后代目的地并验证同名冲突。系统打开入口明确反馈需要桌面客户端；不虚报打开系统目录。

## 浏览器边界

仅通过原生文件选择器获取用户主动选择的 File。文本扩展名且大小不超过 2MB 时调用 `File.text()`；其他文件保留文件名/大小并呈现不支持预览状态。上传同名文件跳过并报告数量，不覆盖现有文本。没有扫描、索引、实际目录写入、回收站、跨空间传输或安装客户端行为。Markdown 文本安全地作为文本节点展示，未引入 HTML 渲染或解析库。

## 验证

子任务执行了 esbuild 内存 JSX transform（无产物写入），语法通过。统一构建、离线验证与安装版/浏览器实点由能力页及共享统筹任务串行执行，不在此宣称已验证。

浏览器检查清单：资料库标题与搜索、文件数量及更多操作；默认空态与 3 个文件；切换页签保留文件变动；根菜单与文件夹菜单；新建与行内名称校验；文件选择、编辑取消/保存、Cmd/Ctrl+S；未保存切换拦截；移动冲突与防自包含；递归删除确认；搜索回调及引用草稿；菜单/对话框 Escape、焦点返回、输入法组合与长名称。
