# 任务侧栏

复用 `SidebarTasks`，由 `ui_kits/enterprise-app/Sidebar.jsx` 接入。样例入口：[侧边栏](sidebar.card.html)。沿用现有字体、冷灰与开源绿色 tokens；新增菜单层级归 `tokens/elevation.css` 管理。

- 侧栏与后代统一使用 border-box；展开外宽由 `--cs-sidebar-width` 定义为 280px。一级导航和任务滚动区左右留白均为 12px，任务按钮内部左右留白为 10px。任务区使用独立的 `cs-sidebar-task-scroll` / `cs-sidebar-task-row` 类名，页面正文响应式规则不得覆盖其留白、伸缩或滚动行为。
- 置顶、最近任务、空间按单列顺序排列，不使用任务／空间页签；置顶项只在置顶区出现，空间归属仍保留。渠道任务按渠道分组。
- 选中由任务 ID 决定，分组展开与任务选中相互独立。「空间」标题可整体收起／展开空间区，默认展开；整体收起不会重置各空间的独立折叠状态。具体空间与「空间」分区标题左对齐，使用灰色空间图标与较深文字区分，不额外加重名称或扩大组间距；组内任务保留缩进，不增加色块或分割线。时间与更多操作共用行尾，键盘聚焦也显示更多操作。
- 任务行仅显示名称、运行指示器和行尾时间／更多操作。运行指示器取 running > 0，悬停及无障碍名称为「运行中」，不显示执行方数量；排队和计划字段保留在数据中，但不在侧栏展示。无指示器不代表完成。
- 自动化来源图标隐藏。无标题显示「新任务」。任务保持单行；长标题单行截断并保留 title。
- 六组操作：置顶／取消置顶、行内重命名、复制、移入／移动／移出空间、合并、删除。复制与合并创建新样例任务，保留源任务；合并从搜索弹窗中至少选择两项。运行中不额外禁用这些操作。
- 普通／空间任务支持内联创建；长列表加载更多；菜单支持上下方向键与 Escape，弹窗使用原生 dialog 聚焦与关闭行为。

功能依据：`src/renderer/modules/conversation.js` 的 `_renderConversationSidebarItem`、`_convTaskStatusLine`、`_conversationActionItems`、`_openConversationMergePicker` 与 `renderConversationList`。

全部数据变化仅存于当前预览组件，刷新或重置恢复。运行、排队、计划是固定状态快照，不模拟任务执行，不修复客户端状态刷新问题。复制／合并只演示列表结果，不复制真实消息与文件。通用导航仍由外层页面路由负责，空间管理沿用工作空间页面。

样例页只显示一个侧栏，通过场景选择查看默认、选中、空间收起、长列表、空数据和侧栏收起，hash 保留直达能力。

## 上游数据更新

`items` 或 recent/pinned/spaces 是实时快照，组件按内容变化合并新增、更新和移除任务；保留用户菜单的置顶、重命名、移动、本地创建及删除状态，不因父组件产生新数组而重置。任务应传稳定 id；相同标题在不同空间互不合并。无 id 的空间字符串采用空间限定回退 id，无法保证重命名身份连续，正式调用应提供 id。UI Kit 的元组任务在 Sidebar 适配层用对象身份分配稳定 id；创建新元组得到独立任务。
