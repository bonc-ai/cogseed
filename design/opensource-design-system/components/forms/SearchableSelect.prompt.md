SearchableSelect — 选项超过 8 条时从 Select 升级而来；搜索行 h 34、列表 max-h 240、页脚计数使用系统非衬线。

```jsx
<SearchableSelect value="静安小组" recent={['虹口小组']} total={47}
  options={['静安小组','虹口小组','浦东小组','徐汇小组']} placeholder="小组" />
```

匹配字段加粗、不改颜色；无结果显示一行原因与办法，不显示空白面板。

展开后点击组件外部收起菜单；组件内部操作保持可用，选择选项后收起。


打开后聚焦搜索输入，方向键进入结果；向上返回搜索框，Enter/Space 选择，Escape 关闭并返回触发器。空结果保留搜索入口。浮层复用共同定位，避免滚动裁切。
