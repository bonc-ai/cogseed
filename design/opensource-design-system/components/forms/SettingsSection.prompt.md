# SettingsSection · 设置分组

设置页面内部的共享分组容器。传入 `title`、`children`，按需提供标题右侧 `actions`；不默认添加描述文案。

- 所有设置分组统一采用 1px 浅边框、16px 内边距与现有卡片圆角，不提供样式变体。
- 加重标题、标题下 12px、组间 32px 留白；组内设置项保持紧凑。
- 标题下不加横线；细分割线由组内设置行提供。不要嵌套分组卡片或额外添加阴影、底色和页面覆盖样式。
- 标题固定使用 h2；容器以标题命名为可访问 section。右侧操作复用 Button 等控件，窄屏允许换行。
- 不管理折叠、保存、网络或数据状态；这些行为由页面传入。当前不提供折叠变体。

组件源文件、类型契约与独立预览一同维护。实际应用见 `ui_kits/enterprise-app/SettingsScreen.jsx`、`SettingsPanels.jsx`。
