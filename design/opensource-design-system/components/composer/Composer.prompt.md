Composer 是复合组件，复用 Popover、Button、IconButton、Icon 组合输入台与执行配置，无需先新增基础组件。

底栏保持附件 → 上下文标签 → 访问权限 → 执行配置 → 语音 → 发送。执行配置显示实际模型与推理强度；点击向上展开「执行配置（本次任务）」，包含当前模型、提供方及自动／关闭／低／高四个互斥选项；外接智能体必须沿用现有 modelSupported / effortSupported 能力判定，模型不可控时只读展示，强度不可控时禁用并说明原因。修改只作用于本次任务。点击外部或 Escape 收起。

沿用本设计系统的开源绿色、圆角和阴影，结构与状态继续复用现有 Composer。

```jsx
<Composer width={720} value={txt} onChange={setTxt} spaceBound
  modelName="DeepSeek V4 Flash" providerName="DeepSeek"
  reasoningEffort={effort} onReasoningEffortChange={setEffort}
  contextTags={[{label:'@ 项目助理',selected:true},{label:'华东团队空间'}]} />
```

模型选择由 onSelectModel 交给宿主；本轮仅展示当前模型，不扩展模型列表。普通任务的 @ 范围为智能体与技能；绑定空间后增加产物与资产。选择器复用 Popover、Input、Tabs、Button 和 Icon。

输入台状态在同一组件页内纵向分组，见下方说明。正式客户端原有发送判定、执行中点击停止、Enter 排队和队列悬浮组件保持不变。预览仍使用原有文字发送演示，不代表客户端接入。

访问权限仅在已有对话（placement="conversation"）显示，位于工作空间之后；首页不显示，不新增权限预选或创建时携带权限的流程。复用 Button、Popover 与 Icon，默认「请求批准」，可选择「完全访问／帮我批准／请求批准」；选中后收起并更新标签。permissionMode 与 onPermissionModeChange 可由宿主控制；未传入时只在当前预览内保存选择，不改变客户端权限。

选择与引用：输入 @ 或点击底栏智能体入口，均从底栏 @ 入口向上展开面板，搜索按当前分类的名称与说明过滤。普通任务含智能体／技能；绑定空间增加产物／资产。空列表与搜索无结果分别提供原因及下一步。智能体为单选并更新底栏；技能插入正文，产物与资产显示为独立可移除引用并去重；候选项只显示默认与 hover 状态，不展示选中底色、勾选或按下状态；再次打开面板也不标记已添加项。选择后收起并返回正文，Escape 或点击外部也可收起。权限、执行配置与选择器互斥展开。

默认输入台只把产物／资产放入上方引用行；技能选择在光标处插入可读的 @技能名，正文内不可局部编辑的技能标签外观在正文编辑组提供独立样例。正式接入时必须保留现有 token 编辑器、隐藏标识、复制粘贴、草稿与发送协议，不能以设计预览的纯文本序列化替代。选择器使用本地示例数据，mentionItems 可替换为宿主已过滤的数据；前端分类与示例页脚不代表权限校验。场景切换按钮仅属于组件审阅页，切换时重置草稿与选择，避免把空间引用带入普通任务演示。首页、任务页继续复用同一 Composer。

@ 面板采用紧凑布局：宽 360px，锚定底栏 @ 入口，距入口 6px；省略独立标题栏，Tab 在上、搜索框在下，搜索只作用于当前分类；分类与搜索框间距 8px。候选行最小高度 44px，列表随内容增高、最高 160px 后滚动，避免少量结果仍占据大块空白。保留分类和权限范围页脚。

弹层标题按信息需要保留：@ 与访问权限面板不重复入口名称；执行配置保留「执行配置（本次任务）」，说明模型与推理强度的共同作用范围。

三种面板统一由 Popover 锚定模式承载，定位、外部点击、Escape 与焦点返回集中在共享组件。候选行、权限行和模型行复用 PopoverItem；输入台只保留各面板的业务内容与互斥展开状态。统一规格见 ../feedback/Popover.prompt.md。

底栏 @ 与访问权限入口统一使用 Button size="sm" 的 28px 高度。输入台组合层不得另行覆盖高度；基础 Button 继续作为尺寸规则来源。

@、访问权限、执行配置入口统一通过输入台内部 ComposerTrigger 组合 Button size="sm"：高度 28px，基础按钮默认圆角和细边框，白底，hover 或展开时统一浅灰底；横向内边距 9px、内容间距 6px、字号 ui-sm、下拉图标 12px。模型的推理强度小标签仅表达附加信息，不改变按钮高度。入口不再逐个覆盖尺寸或展开背景。

输入台宽度限定 480–900px，由布局 token 统一维护，宿主至少提供 480px 可用空间。配置栏始终 nowrap；输入台内容区不超过 720px 时，@、空间、权限、执行配置入口折叠为图标，保留 title、可访问名称和原有弹层锚点、内容与动作。断点依据组件宽度而非窗口宽度，适配侧栏占用。宽度审阅通过 480／720／900px 三档切换，不改变场景数据。

同一个输入台组件页内按以下顺序纵向平铺，各状态同时可见，不拆成不同页面，不依赖动态切换：

- [01 发送与排队](composer.card.html#sending)：空白、可发送、提交中、执行中、停止中、队列及编辑态。
- [02 附件](composer.card.html#attachments)：拖入、上传中、就绪、失败、多附件、长文件名与视频说明。
- [03 语音](composer.card.html#voice)：录音、麦克风结束、完成、权限错误与设备错误文案。
- [04 正文编辑](composer.card.html#editing)：多行增高、200px 滚动、正文内技能标签、480px 窄布局。
- [05 不可发送](composer.card.html#blocked)：上传等待、智能体停用、带附件不能排队、仅附件与仅消息引用的区别。

组合边界：Composer 负责正文及底栏，通过 phase 和宿主回调表示发送/停止/排队；beforeInput、editor、afterInput 接收独立子组件。ComposerQueue、ComposerAttachments、ComposerVoice、ComposerNotice 各自负责展示，不访问业务数据。ComposerRichDraft 仅用于正文编辑审阅，不接入默认输入台的标签数据或真实发送。

业务依据来自 renderer/conversation.js 的提交与发送按钮路径，以及 stt-input.js 的取消路径：运行时按钮停止，Enter 排队；上传中阻止提交；带附件不入队；仅附件不可发送，消息引用可单独发送；取消录音清空转写。实际上传失败路径移除临时附件并显示错误提示，不要求保留失败卡片。停止中与首页提交中沿用现有禁用状态；空白、上传等待等只在提交时拦截，不新增按钮提前禁用规则。Enter 发送，Shift / Ctrl / Cmd + Enter 换行；所有快捷键跳过 IME composition。停用会话锁定来自绑定智能体，不能承诺切换 @ 接收者即可解除。

预览范围：上传只使用文件名示例，波形与实时转写使用固定内容；不会请求麦克风、读取文件正文或访问真实任务。队列不调用真实服务；点击停止会模拟结束当前回复并开始下一条。正式客户端在当前会话回复结束（包括中止）后尝试发送下一条，停止按钮不表示暂停队列。初始状态各自固定；交互仅用于验证该局部组件。构建成功不等于浏览器验证或正式客户端验收。

工作空间入口复用 ComposerTrigger、Popover、Input、PopoverItem，宽 280px，锚定入口向上 6px，支持搜索、空结果、单选与当前项对勾。默认工作区为空 id；选中空间后 @ 增加产物／资产，切回默认工作区只保留智能体／技能。切换空间仅改变所选空间与候选分类，保留正文及已选引用；不新增切换时自动清空引用的行为。spaceId/onSpaceChange 支持宿主控制，spaceOptions 提供候选项；默认候选均为演示数据。组件页内保留工作空间交互样例，默认收起，点击入口展开，无需页面跳转。

审阅页不为浮层保留固定空白：基础输入台与工作空间样例在说明下间隔 12px 排列，弹层默认收起、点击入口浮出；浮层不参与页面占位。

场景高度通过 placement 区分：首页 home 正文 80–260px，对话 conversation（默认）正文 64–200px；不包含附件、引用、提示和底栏。尺寸与自动增高逻辑共用这两个边界。HomeScreen 与 TaskScreen 显式指定场景。审阅页先上下展示两种默认态，再平铺原有状态；左侧 sticky 锚点目录定位八组内容并高亮当前组，窄视口改为页首目录，不隐藏或折叠状态。宽度样例选择值为可用空间内的目标上限，避免新增目录挤出横向溢出。

附件现采用 32px 单行横向滚动标签，不展示大小／状态文字；语音仅将现有波形、聆听状态与取消入口调整到麦克风上方浮层，正文接收转写；结束仍通过麦克风入口，不新增识别中状态、浮层重试按钮或录音期间发送锁。详见 ComposerAttachments.prompt.md 与 ComposerVoice.prompt.md，取代原先多行附件及正文内大语音面板。

正文编辑区域聚焦时不展示 outline 或焦点阴影，保持无内框；适用于 textarea 与正文内技能标签编辑区。底栏按钮保留原有焦点提示。

### 自动化表单

`placement="automation"` 复用正文、附件与 @，隐藏空间、权限、执行配置、语音、发送。Enter 换行；提交由外部表单负责。`selectedMentions` / `onMentionsChange` 保存 agent/skill/connector/library 引用，agent 单选、其余按 kind/id 去重。宿主提供 `mentionItems`，编辑时回填引用；文件读写仍由宿主负责。

首页与对话可用 `recipient` / `onRecipientChange` 受控接收者，未传时保持内部选择；模板填入后通过 `editorSelection={start,end,revision}` 聚焦并选择待填写部分，无需访问组件 DOM。


受限容器内最小宽度为 min(100%, 480px)，不得越过对话区域覆盖侧栏。底部工具栏的换行归组件 composer.css 管理，720px 以下容器自动折叠文案并允许换行；页面不覆盖该契约。
