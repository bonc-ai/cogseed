# CogSeed 开源版 Design System 适配 Handoff

状态：设计适配与确认，2026-09-09。用户已明确：本轮基于已有组件修改、核对 open-source design system，不直接修改正式客户端代码。设计稿完成和浏览器检查不代表用户已确认。

## 1. 当前目标

复用本包已有组件、布局与交互，完成开源主题、品牌和页面样例适配，形成一套可浏览、可逐项确认的设计系统。保留 CogSeed 开源版绿色、现有 Logo 与松鼠图形。

工作只在 `cogseed-product/docs/design/opensource-design-system/` 内进行。`cogseed-source` 可作为只读的品牌资源和功能依据；本次不启动客户端重构、构建、发布或源码提交。

## 2. 依据与边界

| 内容 | 依据 |
| --- | --- |
| 布局、文字层级、控件、间距与通用交互 | 本包当前规范及已有共享组件 |
| 品牌与颜色 | 开源客户端已有绿色、Logo 与松鼠；通过设计 token 映射 |
| 功能、名称和条件 | 既有组件及页面的实际语义，必要时只读核对客户端 |
| 企业来源 | 保留追溯记录，不沿用专属字标、业务版品牌和专属授权流程 |
| 设计确认 | 由用户确认，不以构建通过或 Agent 修改代替 |

知识库与运行中心不在本包页面样例范围内，不补建这两个页面。已有资料库范围保留。调整组件外观和样例内容不改变真实业务逻辑或权限规则。

## 3. 修改顺序

1. **核对规范。** 阅读 `AGENTS.md`、`SKILL.md`、`readme.md` 和相关 `.prompt.md`、`.d.ts`；清理当前指导中的业务专属要求，历史记录单独保留。
2. **映射主题。** 品牌绿 `#0E9F6E`、操作深绿 `#0A7A55`、选中底 `#E2F5EC`、主文字 `#14281E`、页面底 `#FBFDFC`、次级面 `#EDF3EF`。主要操作、链接、焦点、选中和成功状态分别定义；核对可读文字对比度。
3. **复用组件。** 优先调整既有 Button、IconButton、Avatar、Composer、Card、Tabs、PageHeader、表单和浮层。共享差异先落到组件与 token，再用于页面；不以页面覆盖掩盖组件问题，不另建一套基础组件。
4. **适配样例。** 覆盖登录、首页、工作空间及详情、自动化、认知资产、智能体／技能／连接与管理编辑页、任务、设置。保留原有可点击路径和内部标识，业务专属默认内容改为通用工作场景。
5. **构建与检查。** 在本包运行 `node tools/build.cjs` 和 `node tools/verify.cjs`，同步生成 JS、bundle、类型入口与清单。检查代表页面、受限视口、键盘及状态；结果记录在 `verification.md`。
6. **交付确认。** 给出可打开的设计系统、实际改动和待确认项，等待用户的设计意见。

## 4. 本地预览

在本设计包运行：

```sh
node tools/preview.cjs --port 4174
```

访问本机 `http://127.0.0.1:4174/`。复用已有 esbuild 环境，可通过 `COGSEED_ESBUILD_PATH` 指定。JSX 是设计预览源码，浏览器加载构建生成的 JS，不接入真实后台。

## 5. 交付检查

- 规范、组件卡片和页面使用同一套开源 token 与品牌资源。
- 页面默认展示不再使用专属字标、业务版徽标或企业专属默认场景；历史文件名与记录保持可追溯。
- 按影响范围检查默认、悬停、焦点、禁用、加载、错误与空状态。
- 检查入口直达、刷新、跳转、菜单 Escape 与焦点返回；不以离线契约检查替代浏览器证据。
- 分别陈述设计调整、生成结果、浏览器检查、待用户确认和未验证项。

正式客户端接入是后续独立任务。只有用户明确要求实施客户端时，才进入对应源码仓，重新核对分支、共享组件契约、业务保留点和运行验证要求。
