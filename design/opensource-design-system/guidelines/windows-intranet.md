# CogSeed 开源版 · Windows 与内网适配规范

本规范与颜色、文字、间距规范共同构成当前设计基线。Windows 与 macOS 使用同一套组件和业务交互；UI Kit 是页面样例，不能据此认定企业服务或客户端已实现。

## 文字与对比度

| 用途 | 字号 | 字重与使用规则 |
| --- | --- | --- |
| 正文、任务输入 | 15px | 400，正文行高 1.75 |
| 通用导航、按钮、字段 | 14px | 400；关键标题可用 500 |
| 紧凑导航、表格及控件附属文字 | 13px | 不通过整体缩放降低字号 |
| 辅助说明 | 12.5px | 与实际底色至少 4.5:1 |
| 分组标签、元数据 | 12px | 不得承载只能靠更大字号读懂的关键操作 |
| 展示标题 | 34px | 仅保留既有非衬线问候风格，避免重复抢占层级 |

普通文字及占位提示与实际背景至少 4.5:1，大字至少 3:1。辅助文字使用 `--cs-text-muted`，禁用文字才使用 `--cs-text-disabled`。透明背景须按合成后的实际底色检查。状态色用于状态，普通链接使用 `--cs-link`；主要操作按钮的白字须检查整个渐变及悬停增亮态；加载状态保留文字对比度，用进度指示表达等待。

规则参考：[W3C Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

## 字体与平台

- 标题、正文、导航、表单、辅助文字、数字和代码统一使用系统默认非衬线字体。CSS 只指定通用类别 `system-ui, sans-serif`，不绑定任何具体字体名称。
- 不随包提供字体文件，不定义 `@font-face`，不调用外部字体服务。系统与浏览器决定实际字形，允许两端存在自然字形差异。
- 数据列通过列宽与对齐规则保持整齐；可使用 `tabular-nums`，不以字体支持等宽数字作为布局前提。
- 设计稿与 UI Kit 统一以 macOS 窗体为基础，左上角采用三色窗口按钮示意，快捷键使用 ⌘K / ⌘S / ⌘↵。
- Windows 原生窗口按钮、标题栏命中区域及 Ctrl 快捷键由客户端构建按平台适配。两端共用组件、页面结构与业务交互。
- 设计预览不按浏览器所在系统切换窗体；原型三色窗口按钮只展示布局，不执行关闭、最大化或最小化。

## 窗口与缩放

- 1440×900 为参考画布，不得锁定为运行尺寸。页面使用可用窗口宽高；页脚、输入区域与关闭动作保持可到达。
- 常规支持范围从 960×600 CSS px 起；低于该尺寸仍应允许滚动访问内容，不以整体缩小页面适配。
- 侧栏展开宽度及最小宽度统一为 280px，使用 `--cs-sidebar-width`；受限窗口不缩窄侧栏，保留原有手动收起行为。
- 首页正文最大宽度 720px，任务正文最大宽度 760px，并允许缩窄。小窗口压缩页边距和顶部留白，不压缩字体。
- 空间卡片随宽度从三列变为两列、一列。任务信息面板保持在正文右侧且不覆盖对话；受限宽度可关闭面板，设计场景画框允许横向滚动访问并排内容。
- 宽表格允许自身横向滚动；正文与整个应用不得因此横向溢出。
- 检查 1366×768、1440×900、1920×1080，以及 Windows 125% / 150% 缩放后的可用内容区域。浏览器视口模拟只能提供布局证据，Windows 字体栅格化和系统 DPI 必须在真机补验。

## 内网交付

- 字体直接使用本机系统默认非衬线；React 预览运行资源、CSS、组件脚本和图标随包分发。页面不得发起字体下载或依赖外部 CDN。
- 预览页面加载预编译的普通 JS；JSX 作为可编辑源文件保留，浏览器不依赖 Babel 在线编译。
- `assets/asset-manifest.json` 保存资源来源、大小、SHA-256；来源 URL 仅作追溯，不能被页面运行时调用。运行资源的许可证随包交付。
- 文件修改后，使用已有 esbuild 环境运行 `node tools/build.cjs`；可用 `COGSEED_ESBUILD_PATH` 指向已有 esbuild 模块。构建不会下载依赖。
- 原生客户端按现有本地资源与 IPC 架构集成设计，不因展示本 UI Kit 在 Electron main 中新增 HTTP 服务。
- 内网完整显示仅指界面资源可用；模型、登录及业务调用仍依赖相应企业服务。

## 验证要求

检查首页、工作空间、任务页和代表组件：普通文字对比度、最小字号、窗口溢出、macOS 基础窗体、快捷键文字、零字体请求、本地脚本加载和错误日志。记录“浏览器已验证”和“Windows 真机待验证”，不互相替代。当前记录见 [verification.md](../verification.md)。


## Windows 高对比度

系统强制颜色在绘制阶段接管颜色，内联样式不构成豁免。共享 accessibility.css 使用 `@media (forced-colors: active)`：操作边界使用 ButtonBorder，焦点与选择提示使用 Highlight，不依赖会被系统去掉的 box-shadow。不得以 `forced-color-adjust:none` 关闭系统接管。

原生按钮、单选和复选保留系统语义。--cs-attention 仅用于非文字状态图形，文字使用 --cs-attention-ink；状态正文不通过 opacity 调淡。普通 Alert 的颜色配对纳入离线对比度计算。

验收仍需 Windows 真机开启高对比度，检查按钮边界、当前页、单选/复选、表格选择、模态焦点及 125%/150% DPI；CSS 与静态检查不证明真机验收。
