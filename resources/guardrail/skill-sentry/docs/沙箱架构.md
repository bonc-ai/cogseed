# 沙箱隔离架构说明

## 威胁模型

本扫描器的输入是**待检测的、可能是恶意的外部 Skill**——这是主动把不可信内容
喂进系统。与普通工具"沙箱防自己出 bug"不同，这里沙箱是**防被测内容攻击宿主
和 Agent**。主要风险：

1. 扫描过程可能执行被测内容（osv-scanner 解析依赖、未来的二进制动态分析）。
2. 解压环节可能遭遇 zip 炸弹、符号链接、超大文件。
3. 被测 Skill 可能内含提示注入，专门攻击"读它的那个 Agent"。

## 核心架构：Agent 不直接接触不可信内容

```
┌─────────┐   调用    ┌──────────────┐   起一次性容器   ┌─────────────┐
│  Agent  │─────────▶│  agent_gate  │───────────────▶│   沙箱容器   │
│ (决策)  │◀─────────│ (编排/裁决)  │◀───────────────│ (接触不可信) │
└─────────┘  JSON裁决  └──────────────┘   JSON报告      └─────────────┘
```

- Agent 只调用 `agent_gate.evaluate_skill()`，拿到精简裁决（verdict + 摘要）。
- Agent **看不到被测 Skill 的原始文本**，规避间接提示注入。
- 真正接触不可信内容的是断网、只读、非 root、用完即焚的沙箱容器。

## 隔离措施清单（run_sandboxed_scan.sh）

| 措施 | Docker 参数 | 防御目标 |
|---|---|---|
| 全程断网 | `--network none` | 数据外传 / SSRF / 认知资产外传 |
| 被测只读挂载 | `-v skill:/target:ro` | 扫描器篡改被测内容 |
| 根文件系统只读 | `--read-only` | 落地持久化 |
| 内存临时盘 | `--tmpfs /tmp` | 残留、跨扫描污染 |
| 非 root | `--user 10001` | 提权 |
| 丢弃能力 | `--cap-drop ALL` | 内核层攻击面 |
| 禁止提权 | `--security-opt no-new-privileges` | setuid 提权 |
| 进程数限额 | `--pids-limit` | fork 炸弹 |
| 内存/CPU 限额 | `--memory / --cpus` | 资源耗尽 / zip 炸弹 |
| 用完即焚 | `--rm` | 状态残留、容器复用污染 |

## 裁决语义

| deployment_recommendation | Agent verdict | 含义 |
|---|---|---|
| ALLOW | allow | 放行 |
| CAUTION | review | 转人工复核，不自动放行也不直接拒绝 |
| DO_NOT_INSTALL | deny | 拒绝 |

## fail-closed 原则

- 沙箱内部出错 → verdict=review（交人工），不放行。
- `require_isolation=True` 且无 Docker/镜像 → verdict=deny（核心环境推荐）。
- `require_isolation=False` 且无沙箱 → 降级本地扫描，但结果标注 `isolated:false`
  + warning，让上层知道这次裁决可信度低。

## 使用

```bash
# 1. 构建沙箱镜像（需要 Docker）
bash 06_sandbox/build.sh

# 2a. 命令行隔离扫描
bash 06_sandbox/run_sandboxed_scan.sh <skill目录> <报告输出目录>

# 2b. Agent 集成（推荐核心环境用 require-isolation）
python3 06_sandbox/agent_gate.py --skill <skill目录> --require-isolation
```

Agent 内部集成示例：

```python
import sys; sys.path.insert(0, "06_sandbox")
from agent_gate import evaluate_skill

verdict = evaluate_skill("/path/to/external-skill", require_isolation=True)
if verdict["verdict"] == "deny":
    reject_skill(verdict)          # Agent 只依据结构化裁决决策
elif verdict["verdict"] == "review":
    escalate_to_human(verdict)
else:
    install_skill()
```

## 后续加固建议

1. 动态二进制分析上线时，沙箱从"建议"变"绝对必需"，且需额外网络镜像取证。
2. 离线漏洞库：当前 osv-scanner 在断网下能力有限，需预置本地 OSV 数据库到镜像。
3. 更强隔离可评估 gVisor / Kata / Firecracker 微 VM 替代普通容器。
