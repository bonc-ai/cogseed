# Governance boundaries

The Skill interprets the user's explicit creation or editing request. The host owns identity, source access, version checks, confirmation, and persistence. Use governed tools rather than direct resource access.

An explicit precise user delta against a valid complete prior decision is human authorization for that delta. Creation, AI rewrites, unreviewed prior contracts, structural changes, and additional impacts require the host's complete preview and human confirmation. Reading paused content does not enable task use.

Changing this package cannot grant creation authority or tool permissions, verify effectiveness, or release a new production capability. A model's source/owner label cannot replace the host's real human instruction and complete decision. Package evolution remains capped at `staged`; `production_release_allowed: false`.
