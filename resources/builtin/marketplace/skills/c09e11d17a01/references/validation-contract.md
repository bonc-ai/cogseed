# Validation contract

Host boundary scenarios are exercised by `test/main/features/cognition-edit.test.ts`: full preview establishes an edit root; an exact patch continues it; shared R edits commit through the asset; paused/owner-only inspection stays management-only; revoked sources never reveal text; ambiguous/background targets and stale baselines cannot silently write; factual correction preserves history; existing standalone asset calls remain usable.

HITL: explicit precise user delta + complete prior human decision, or complete preview → confirmation → execution. Denial/cancellation leaves content unchanged. The model never confirms its own proposal.

Creation adds a distinct complete human root, not a manual exemption or forged nightly capture. Cover cognition, standalone ontology and joint shared rules; cancellation, duplicate submission, stale baseline and source revocation must not produce a half-commit. Default-dialogue model tool selection and the production approval stream need separate real-model evidence; an extra-tools relay or recorded transport does not establish that path.

Use only necessary scoped checks after evaluating uncertainty and cost. Model-driven end-to-end evaluation is separate from the synthetic host contract and follows the current authorized model route. Package checks do not establish real task effectiveness.
