# 商品文案撰写技能

把商品参数转化为高转化文案。

## 使用场景
- 新品上架（标题+主图文案+详情页）
- 老品优化（点击率/转化率优化）
- 广告投放素材

## 工作流程
1. 收集商品信息：功能、材质、参数、用户评价、竞品卖点
2. 提炼核心卖点：FAB 法（特性→优势→利益），选出 3 个主打卖点
3. 写标题：关键词前置 + 卖点 + 数字
4. 写主图文案：每张主图一个信息点（卖点/场景/促销）
5. 写详情页：痛点开场 → 卖点分段 → 参数 → 售后 → 信任背书
6. 合规自查：广告法违禁词、极限词、资质要求

## 输出
标题（≤30 字）+ 主图文案 5 条 + 详情页文案 + 合规自查
