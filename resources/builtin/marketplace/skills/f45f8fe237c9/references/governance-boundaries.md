# Governance boundaries

- 当前包：`SKILL-FRAME-AI-PRODUCT-001`，状态 `candidate`。
- 当前退出 Gate：`Frame Gate`；AI 只能准备请求，不能形成终态决定。
- 默认权限 A2；仅在明确确认、可逆、可审计的项目内动作上达到 A3。
- A4、外发、生产写入、权限提升、金钱、发布和全局安装默认禁止。
- 自动化最多提出 `staged_eligible`；`staged` 仍需独立 owner 决定。
- 不得宣称 release ready、production、published、客户价值或 Level C。
- 保护面变更必须先进入 Change Candidate 并重跑受影响包与全 12 E2E。
