# 小红书笔记创作技能

用于把商品/品牌资料转化为小红书风格的种草笔记（标题 + 正文 + 卡片文案）。

## 使用场景
- 新品的种草笔记
- 活动节点（大促/上新）内容铺量
- 素人/达人笔记素材

## 工作流程
1. 收集素材：商品卖点、价格、人群、使用场景、品牌调性
2. 定选题：按人群痛点 × 商品卖点 × 平台热点组合
3. 写标题：≤20 字，含数字/疑问/悬念，不夸大违禁词
4. 写正文：开头 3 行抓人 → 分段卖点 → 真实体验口吻 → 结尾引导
5. 出卡片：封面文案（大字）+ 正文卡片（每张一个信息点）
6. 自查：违禁词（最/第一/100%）、敏感词、广告法合规

## 输出
标题 + 正文 + 3-5 张卡片文案 + 违禁词自查结果
