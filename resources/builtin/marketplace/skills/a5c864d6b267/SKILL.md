# 电商比价调研技能

对目标商品做多平台价格调研，辅助定价与促销决策。

## 使用场景
- 新品定价
- 大促前调价
- 竞品价格监测

## 工作流程
1. 确认商品关键词 + 平台清单
2. 逐平台搜索：记录价格、销量、店铺类型（旗舰/专营/个人）
3. 统计价格带分布：低/中/高 + 主力价格带
4. 记录促销节奏：日常价、大促价、满减规则
5. 输出定价建议：建议售价 + 促销价 + 毛利测算

## 输出
比价表（平台×价格×销量）+ 价格带结论 + 定价建议
