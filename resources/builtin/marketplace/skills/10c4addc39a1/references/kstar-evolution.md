# KSTAR Evolution · v0.1 Candidate

Research and report execution is recorded as a KSTAR episode:

```text
K/S: domain, research plan, files, official-source requirements
T: produce a complete ontology landscape/alignment volume
Â/R̂: planned research coverage, expected source quality and report completeness
A/R: actual queries, opened sources, gate result, report validation, Word/render result
ΔA: deviations from planned research/execution
ΔR: differences in source coverage, concept/process coverage, report quality and reviewer corrections
```

`ΔA != 0` gates trust in `ΔR`. A missing web-search/open step is an execution failure, not evidence that ontology content is correct or incorrect. One run creates candidate improvements only. Any change to protected surfaces—primary-source rules, research gate, HITL, audit or staged ceiling—is prohibited.
