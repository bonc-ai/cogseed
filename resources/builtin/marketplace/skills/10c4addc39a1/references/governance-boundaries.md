# Governance Boundaries · v0.1 Candidate

- Mandatory website research and source-verification gate cannot be bypassed.
- Search snippets and model memory cannot replace official sources for current facts.
- The computed gate may advance only to report drafting; it is not professional approval or release permission.
- High-impact decisions require authorization, HITL, audit and review/appeal.
- Customer/private semantics do not flow into shared assets without explicit data-boundary approval.
- Automatic promotion ceiling is staged.
- Production release, official publication and external conformity claims require independent human decision processes.
