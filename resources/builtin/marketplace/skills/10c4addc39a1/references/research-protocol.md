# Research Protocol · v0.1 Candidate

1. Retrieve and inventory all user files.
2. Create `research-plan.json` with policy, domestic-standard, international-standard and version/status questions.
3. Search the web through approved Agent tools.
4. Use secondary sources only to find issuing-authority or standards-body originals.
5. Open and read every selected source; inspect relevant PDF pages when tables, figures or scans matter.
6. Record query logs, page/section, access time, source type, primary/official flags, version/date, content hash and claim bindings in `web-research-ledger.json`.
7. Resolve policy-date, policy-scope and standard-version conflicts.
8. Run `validate_research_bundle.py`; stop if the computed gate fails.
9. Lock official policy scene and domain boundary.
10. Build the P/S/I/E/A/R report evidence ledger.
11. Model parties, roles, systems, concepts, relations and processes with four-layer separation.
12. Perform role-based standards alignment.
13. Model Agent authorization, HITL, audit and KSTAR/ECS.
14. Run the full report pipeline, render, inspect every page and audit accessibility.
15. Hand off only as a staged candidate.
