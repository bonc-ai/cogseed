# External Standard Alignment Rules

Roles: `semantic_backbone`, `code_system`, `exchange_format`, `event_telemetry`, `provenance_credential`, `governance_reference`, `local_mapping`.

Mappings: `exact`, `narrower`, `broader`, `related`, `local extension`.

Every standard must state official organization, researched version/date, coverage, reusable concepts, role, mapping, backbone recommendation, strengths, gaps, jurisdiction/license constraints and local extension. An exchange schema is not automatically the business-semantic backbone.
