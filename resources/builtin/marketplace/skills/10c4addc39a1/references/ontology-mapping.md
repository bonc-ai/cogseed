# Ontology Mapping

TBox: DomainBrief, Source, Material, Stakeholder, Role, SystemOfRecord, CanonicalConcept, RelationTriple, Process, Event, Decision, RuleConstraint, RiskControl, KPI, StandardAsset, Alignment, AgentGovernance, ClosedLoop, KSTARStage, ReportArtifact, ValidationFinding, ReviewDecision.

Shared mapping: Stakeholder→Party; role→Role; Agent governance→Agent/Capability; scope→Situation/Goal/Policy; process→Process/Task/Decision/Event; source/evidence→InformationObject/Observation/Evidence; risk-control→Risk/Control; KPI→Measure/KPI; closed loop→Episode/Learning; applications/APIs→System/Interface.

ABox stores report-generation episodes, evidence and review decisions. Real private records are excluded from the distributed package.
