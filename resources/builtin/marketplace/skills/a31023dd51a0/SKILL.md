# 销售数据复盘技能

周期性销售数据复盘，把数字变成行动。

## 使用场景
- 日/周/月销售复盘
- 大促后复盘
- 广告投放效果评估

## 工作流程
1. 拉取数据：GMV、订单量、客单价、转化率、流量来源、广告花费/ROI
2. 结构分析：
   - 流量：免费/付费/内容渠道占比变化
   - 转化：商品转化率排名（找出拖后腿的）
   - 客单：件单价/连带率
3. 归因：变化来自大促/上新/投放/竞品动作
4. 输出结论：3 个问题 + 3 个行动项（下周执行）

## 输出
数据总览表 + 问题清单 + 下周行动项
