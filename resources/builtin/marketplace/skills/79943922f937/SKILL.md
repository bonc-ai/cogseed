# 竞品店铺拆解技能

对目标竞品店铺做系统拆解，输出对标行动项。

## 使用场景
- 新店冷启动前找对标
- 店铺增长停滞时找差距
- 每季度竞品监测

## 工作流程
1. 确认竞品清单（3-5 家）：同品类、同价格带、同人群
2. 逐店拆解四维：
   - 选品：TOP 商品、上新节奏、品类结构
   - 视觉：主图风格、详情页结构、品牌色调
   - 内容：渠道分布、笔记/短视频频率、爆款主题
   - 价格：价格带、促销策略、客单价
3. 横向对比表 + 差距清单
4. 输出行动项：按「抄什么 / 避开什么 / 差异化什么」三列

## 输出
对标报告（四维对比表 + 3 条可执行行动项）

- `use_when`：需要对新店冷启动找对标、店铺增长停滞找差距或季度竞品监测：分析竞品店铺的选品结构、视觉风格、内容策略、价格带，输出可落地的对标报告，且已确认同品类/同价格带/同人群的竞品清单。
