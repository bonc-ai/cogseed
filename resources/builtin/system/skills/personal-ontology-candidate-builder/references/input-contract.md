# Input Contract

本技能不需要用户手动喂给它结构化输入——它直接读取最近的对话历史/记忆材料，自己判断哪些内容值得提炼成候选。这个文件说明它在"读输入"时应该关注什么、以及什么情况下应该拒绝提炼。

## 输入来源

- 当前会话或最近若干轮对话。
- 用户明确说"记住这个"之类的交代。
- 已有的记忆条目（USER.md / MEMORY.md 现有内容），用于判断新候选是不是在更新已有条目，避免重复。

## 提炼前必须确认的信息

- 这段内容是**用户本人**的偏好/事实/规则，还是只是任务过程中的临时信息？只有前者才值得沉淀。
- 这段内容是否包含未脱敏的敏感信息（密钥、密码、他人隐私）？有就直接拦截，见下方"拒绝规则"。
- 这条候选是不是已经在候选池或已有记忆里存在过？避免重复生成。

## 拒绝/阻断规则

- 内容包含密钥、令牌、密码等凭据 → 阻断，不生成候选。
- 内容涉及他人未授权的隐私信息 → 阻断，不生成候选。
- 内容是纯粹的任务临时状态（比如"现在在处理第3步"），跟长期偏好/事实无关 → 不提炼，不是失败，只是跳过。
- 无法判断是否已脱敏 → 按未脱敏处理，阻断。
