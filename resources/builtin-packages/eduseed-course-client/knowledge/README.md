# knowledge/ —— 课程知识材料（随插件分发）

本目录只承载**与具体课程无关**的通用方法材料，供学生/教师 Skill 检索：

- 环境准备：Git / GitHub / Node / AI 编码工具链
- 交付物规范：README 标准、commit 规范、演示要求
- AI 协作方法：提示词写法、AI 生成代码的审查红线
- 复盘模板：AAR 七维结构

> 做薄原则：课程专属内容（挑战定义 / 评分标准 / 学习路径）一律不进插件，
> 权威数据在 EduSeed 平台（飞书挑战任务表 + GitHub 内容仓库），客户端经平台 API 按需获取。
> 规则：未经教学负责人确认的材料不得进入本目录（见机制文档 §4）。
