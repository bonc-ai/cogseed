# AAR 复盘模板（七维，v1.0）

> AAR = After Action Review。每次挑战完成后填这七维，写进仓库的 `AAR复盘.md`。
> 质量门：每一维都要有**实质内容**；拒绝"挺好的""学到了很多"式敷衍；必须含失败经验。

## 1. 我学到了什么
具体概念/方法/技能。反例："学会了用 AI"；正例："通过 System Prompt 控制 Agent 角色行为，发现温度调到 0.2 后输出更稳定"。

## 2. 我的流程
| 阶段 | 时间投入 | 做了什么 | 卡点 |

## 3. 我与 AI 的协作
| 协作动作 | 具体例子 | 效果 | 反思 |
标注：好指令 ✅ / 差指令 ❌ / 迭代案例 🔄

## 4. 我完成了什么
交付物最终状态 + 自我评价（对照挑战验收要点逐条）。

## 5. 卡点与突破
最大卡点是什么？怎么解决的？哪个瞬间"这个概念真正进脑子了"。

## 6. 改进方向
下次同类挑战会怎么做不同？（具体到可执行动作，不是"更努力"）

## 7. KSTAR 学习信号
- **R̂（预期）**：我预想的结果/分数
- **R（实际）**：实际结果（AI 初评/教师反馈）
- **ΔR 归因**：偏差来自哪个环节（K 知识 / S 技能 / T 任务理解 / Â 行动）
- **K′（知识更新）**：下次带入什么新知识
