# 学生手册（Student Guide v1.0）

> 适用：AI+X 课程学生 · 使用方式：CogSeed 桌面里的课程插件

## 1. 三步上手

**第 1 步 · 装插件**（学校会给你安装方式，二选一）
- 在 CogSeed 对话里说："帮我安装 EduSeed 课程客户端插件"（学校提供安装链接）；
- 或终端跑：`PLUGIN_TOKEN=<学校发的token> bash install.sh`。

**第 2 步 · 拿密钥**（只需要一次）
1. 浏览器打开平台的 `/companion` 页（学生登录）；
2. 点「生成我的 API Key」→ 复制密钥（只显示一次，丢了就重新生成）。

**第 3 步 · 激活（零配置，只填一样）**
1. CogSeed 里打开「连接 → 插件」→ 点课程插件卡片 → 「平台配置」；
2. 把复制的 **API Key** 贴进「API Key」一栏（新版密钥**自带平台地址**，地址栏会自动填上，无需手填）；
3. 点「保存配置」——角色（学生）与学号会**自动识别**，不用手动填；
4. 然后说一句「**看看我的挑战**」——能列出挑战就说明激活成功。

> 密钥只存你电脑本地，对话、日志、屏幕回显里都看不到；平台按密钥判定身份，不可伪造。

## 2. 每天怎么用

| 我想 | 就这么说 |
|---|---|
| 看有哪些挑战 | "看看我的挑战" |
| 某个挑战要交什么 | "C03 要交什么" |
| 检查我缺什么文件 | "检查我的项目缺什么"（告诉它项目目录） |
| 交作业 | "我做好了，帮我提交 C03" → 它给你看摘要，**你确认才提交** |
| 查分数/评语 | "我上次评分多少" |
| 写复盘 | "帮我写 AAR" |
| 给老师发消息 | "给老师发消息：进度汇报" |

## 3. 提交铁律（会被系统拦的 6 件事）

1. 缺交付物就交（先自查：README/AI日志/AAR/拿来说明）；
2. GitHub 仓库是 private 或不存在；
3. 提交前 24 小时没有新 commit（做完就交，别攒）；
4. AI 日志 / AAR 是编的；
5. 不确认摘要就提交（每次提交都要你点头）；
6. 把密钥、手机号、他人隐私写进仓库。

## 4. 常见问题

| 现象 | 怎么办 |
|---|---|
| "该学生席位未授权" | 找学校管理员开通席位（付费后实时生效，不用重装） |
| "平台不可达/网络错误" | 稍等 1 分钟重试；还不行找老师（平台端维护中） |
| 密钥丢了 | 去 /companion 页重新生成（旧密钥立即作废） |
| 提交后一直"处理中" | 等 1-2 分钟（AI 在评分）；超过 10 分钟在对话里问"我上次提交状态" |
| 挑战显示"已关闭" | 截止了——找老师确认是否延期 |
