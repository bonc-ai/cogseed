# 教师手册（Teacher Guide v1.0）

> 适用：AI+X 课程教师 · 使用方式：CogSeed 桌面里的课程插件（教师身份）+ 平台教师端

## 1. 教师席位与身份

- 教师使用**教师密钥**（由平台管理员签发，`teacher-companion-<工号>`）；
- 激活（零配置）：CogSeed「连接 → 插件」→ 课程插件详情 → 「平台配置」贴入
  **教师 API Key**（新版密钥自带平台地址），保存后角色（教师）与工号自动识别；
- 学生密钥**不能**发挑战（系统强制拒绝）；教师密钥也不能替学生交作业。

## 2. 建挑战（自然语言 + 人工确认）

在 CogSeed 里说："**创建一个新挑战：个人作品集网站，周五截止**"。

助手会：
1. 跟你确认必填项：标题 / 截止时间 / 交付物（支持通配符，如 `README.md, src/**`）/ 评分标准；
2. 缺什么问什么（评分标准可选 4 套模板：build/explore/research/product 生成初稿）；
3. 展示**发布摘要**等你确认——**你确认后才写入平台 + 飞书 + 群公告**；
4. 发布后返回挑战编号（如 `ch-2026xxxxxx-xxxx`），全班可见。

## 3. 批改闭环

| 我想 | 怎么做 |
|---|---|
| 看全班进度 | 平台 `/teacher/analytics`（班级洞察：需关注学生/AI 校准/挑战参与） |
| 批量终审 | 平台 `/teacher/review-batch`（AI 分一键采纳 + 逐条微调 + 通过/打回，走正式终审链路并飞书通知学生） |
| 单条终审 | CogSeed 里说"终审 sub-xxx：通过/打回 + 评语"（**必须先读真实代码**） |
| 看 AI 初评偏差 | 终审列表有 AI 分 vs 你给的分；分差 >15 会标"高偏差请复核"，需说明理由 |

## 4. 红线（系统强制）

- **AI 只初评，终审决定权在你**——平台永远不会替你自动通过；
- 学生提交的唯一写入方是平台任务 Agent，教师不能直接改学生提交记录；
- 打回时给学生说清原因（学生要能据此修改重交）。

## 5. 通知与班级群

- 发布挑战 / 打回 / 通过都会经飞书 Bot 通知学生；
- 班级群公告需要管理员配置 `FEISHU_CLASS_CHAT_ID`（把班级群 ID 给平台管理员）；
- 教师可主动通知：CogSeed 里"通知全班：明天下课前交 C04"。

## 6. 常见问题

| 现象 | 怎么办 |
|---|---|
| 发布被拒"教师席位未授权" | 找平台管理员开教师席位（实时生效） |
| 学生说"看不到挑战" | 检查挑战状态=已发布 + 学生席位已开通 |
| 学生提交一直处理中 | 平台管理员查 `/api/admin/health` 的 AI/飞书指标 |
| 想延期 | 平台管理员在挑战管理里改截止时间 |
