# Remove Legacy P3394 KSTAR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use $superpower-subagents (recommended) or $superpower-executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking via update_plan.

**Goal:** Remove every active legacy P3394 KSTAR path while preserving canonical KSTAR → Recall and generic wake/execution/protocol behavior.

**Architecture:** Delete the obsolete P3394 Engine/Compat subsystem instead of hiding it. Move only the generic dispatch expectation/decision contract into canonical KSTAR ownership, then remove dual-write, boot, IPC, renderer, locale, and test surfaces. Add static deletion proof so old KSTAR cannot be reintroduced accidentally.

**Tech Stack:** Electron main/renderer, TypeScript, vanilla JavaScript, Vitest, JSON locales.
