# 财务人员场景：财务工作中的经验沉淀与复用测试

- 日期：2026-08-17
- 构建：`9232d65e`
- 目的：模拟一位财务人员用 CogSeed 处理日常财务工作，验证 KStar 沉淀链路在**真实业务领域**（财务）下的表现——经验沉淀、复用注入、确认校准、纠偏治理
- 前置：实机已重启；全程我盯后台日志/数据

---

## 场景 F1：报销单制作——沉淀财务模板经验

**操作**（新会话）：
```
帮我做一份 2026年7月差旅报销单，包含交通费、住宿费、餐补，格式要规范
```

**等完成后再发**（触发闭环沉淀）：
```
这个完成了，帮我做一份 8月的差旅报销单，出差人换成王芳
```

**预期**：
- 报销单正常生成（表格/项目/金额结构清晰）
- 「待我处理」出现候选：lesson 类似"报销单按 交通费/住宿费/餐补 分项、注明日期与凭证号"
- 候选**中文**、无模板前缀污染

**后台确认**：候选 1 条 confirmed；资产 maturity=seed，lifecycleStatus=system_precipitated_unverified

## 场景 F2：同类型报表复用——报销经验自动注入

**操作**（同一会话继续，不手动确认）：
```
帮我做一份 9月的差旅报销单，出差人换成李强，预算上限 3000 元
```

**预期**：
- 回复中的「引用资产」能看到 F1 沉淀的报销单经验（注入生效）
- 任务完成后该资产成熟度 → **已迁移验证**

**后台确认**：receipt（turn-id）+ 终态 proof succeeded + receiptId；资产 maturity seed → transfer_validated

---

## 场景 F3：财务报表分析——跨类型经验独立沉淀

**操作**（同一会话继续）：
```
帮我分析一下这个季度的收支情况：收入 85000，支出包含工资 40000、房租 12000、采购 15000
```

**预期**：
- 生成收支分析（收入-支出=利润，比例/趋势）
- 沉淀**另一条**独立候选（"财务报表分析应先算净利再算各项占比"之类），**不与报销单经验合并**

**后台确认**：候选池新增 1 条（与报销单经验 judgment 不同、无 mergedInto）

---

## 场景 F4：用户确认 + 限域——财务专用范围

**操作**：
```
打开「认知 → 待我处理」
找到"报销单"相关候选 → 确认并限域 → 作用范围填：财务报销
```

**预期**：
- 候选晋升为正式资产
- 该资产 scope 标记为"财务报销"（非通用）

**后台确认**：asset.scope 含财务报销语义；user_confirmed 记录（appliedReviewDecisionIds 有值）

---

## 场景 F5：错误经验纠偏——暂停 + 回滚

**操作**：
```
先检查 F1/F2 沉淀的报销经验是否正确：
  如果它把"差旅报销单"写成了"差旅报销单模板的模板"（套娃），
  或金额单位写错（元 vs 万元）→ 打开「版本与治理」→ 编辑修正 或 暂停使用
```

**预期**：
- 能编辑资产内容（版本 +1，历史可查）
- 或暂停后：后续报销任务**不再引用**这条错误经验

**后台确认**：版本 jsonl 多一条（含 snapshot）；暂停后注入日志出现 omitted（asset_paused）

---

## 场景 F6：效果反馈——报销经验确实好用

**操作**：
```
打开「认知 → 使用与证明」
找到报销单经验最近的证明记录 → 评价「有用」
```

**预期**：
- 该资产成熟度 → **效果已验证**（顶档）
- 后续财务类任务优先注入它

**后台确认**：effectiveness-proofs 出现 1 条（outcome=better）；maturity → effectiveness_validated

---

## 场景 F7（对抗）：财务术语混合——防误杀

**操作**（财务任务含大量英文术语）：
```
帮我做一份 2026 Q3 的 P&L 分析，包含 revenue、COGS、opex，用中文输出结论
```

**预期**：
- 正常完成
- 沉淀的 lesson 中文主导（含 P&L/revenue/COGS 术语可接受）
- **不被**语言硬闸误杀

**后台确认**：dominantScript(lesson)=cjk → 不拦截；若日志 dropped 是真 bug

---

## 场景 F8（对抗）：近同财务任务去重

**操作**（连续两个几乎相同的报销任务）：
```
帮我做一份 10月的差旅报销单
（等完成）帮我做一份 10月的差旅报销单，稍微调整一下格式
```

**预期**：
- 只沉淀 1 条相关候选（指纹/语义去重）
- 无双写

**后台确认**：候选池按 judgment 过滤 1 条；无 superseded 双候选
