# 场景测试：沉淀质量修复验证（statement 纯净 + 标题内容化）

- 日期：2026-08-16
- 构建：`a11263ed`（KStar value/action 显式化 + 标题去模板 + statement 纯净）
- 目的：验证修复后的沉淀链路——review lesson → 候选 → 资产，**内容不再被标题残片污染、标题体现内容、语言中文、状态正确**
- 方式：用户在 GUI 跑任务，我盯候选池/资产数据

---

## 背景（修复前的问题）

```
review lesson（好）："当任务要求生成基于用户具体数据的文档时，若缺少必要信息，
应明确提问获取数据，而不应假定可基于通用模板直接产出…"

资产 statement（差）：lesson + "\n可复用经验：数据的文档（如资产简介）时，（报告类任务）"
                        ↑ 标题残片被拼进正文
资产 title（差）："可复用经验：数据的文档（如资产简介）时，（报告类任务）"
                        ↑ 模板前缀 + 截断残片
```

---

## 场景 A：资料类任务（验证纯净沉淀）

**操作**：新会话，发送：

```
帮我写一份 成都城市 的资料，500 字
```

等回复后，发新任务触发闭环：

```
这个任务完成了，帮我写一份 重庆城市 的资料，500 字
```

**后台验证**（我盯）：
```
【review】model 方式 + lesson（若有）
【闭环】judged NEW task → finish → 聚合 → 候选 → 晋升
【候选】status=pending_review（不是 weak_observation）
【statement】= lesson 全文，无第二行标题残片
【title】= 内容核心（无"可复用经验："前缀、无"（通用）"后缀）
【语言】中文
```

**判定**：
- ✅ statement 只有 lesson 一行、title 纯净中文
- ❌ statement 出现"可复用经验：…"第二行 / 标题仍带模板

---

## 场景 B：缺口类任务（验证 gap lesson 沉淀）

**操作**：新会话，发一个**缺前置输入**的任务（如"重构 hello.py"——文件不存在）：

```
把我项目里 hello.py 重构一下，配置不存在就返回默认值
```

等 Commander 回应（找不到文件），发新任务闭环：

```
这个任务完成了，帮我写一份 杭州城市 的资料，500 字
```

**后台验证**：
```
【review】若 lesson 产出（"先确认源码存在"类）
【沉淀】gap 候选 → 资产（statement 纯净、title 内容化、类型合理）
```

**判定**：
- ✅ gap 资产 statement 纯净、标题可读
- ❌ 标题截断残片 / statement 拼接
