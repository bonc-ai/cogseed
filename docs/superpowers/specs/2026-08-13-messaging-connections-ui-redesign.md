# 消息连接管理界面改版设计

**日期：** 2026-08-13
**范围：** 设置 > 触点 > 连接管理
**约束：** 仅重构 renderer 结构、样式和文案，不改变 IPC、实例数据或绑定流程

## 目标

把当前权重相近的“渠道列表、连接状态、实例、关联、归属、行为设置”整理为三层：

1. 左侧“消息渠道”只负责切换渠道，并区分可用与即将支持。
2. 右侧顶部只呈现所选渠道的总览、状态与唯一总开关。
3. 下方按“连接实例、身份与权限、消息行为、危险操作”分组，减少重复状态和卡片嵌套。

## 关键决策

- 保留现有双栏工作区，但渠道栏缩窄并固定在容器左侧。
- 已绑定实例直接承担连接信息展示，不再额外显示“关联机器人 / 已关联”卡片。
- 未绑定实例或新增绑定流程仍显示扫码关联区，所有原事件处理保持不变。
- 实例行中的重复启用开关移除，只保留详情页顶部总开关。
- 归属信息和回复/工作区设置分别进入有标题的设置组；删除操作降低默认视觉权重。
- 页面使用白色工作面、细分隔线和中性灰为主，绿色只表示选中、连接成功和主操作。
- 窄窗口下渠道栏收缩为横向列表，设置行改为单列，避免文字或控件溢出。

## 验收标准

- 第一眼能够确认当前渠道、连接状态和启停入口。
- “已连接 / 已绑定 / 已关联”不再在同一首屏重复表达。
- 用户仍能新增绑定、切换实例、解绑、配置归属、修改回复方式和删除实例。
- 1024px 级桌面窗口无横向溢出；窄窗口下布局可用。
- renderer 结构契约、语法检查、类型检查和应用启动日志通过。
- 重启应用后通过真实窗口检查设置入口、连接管理页和至少一个交互状态。
