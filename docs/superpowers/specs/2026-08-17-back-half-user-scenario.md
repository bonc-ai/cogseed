## 场景 1：任务沉淀 + 用户确认候选（10 分钟）

**目的**：验证「自动沉淀 → 待我处理确认 → 正式资产」的完整用户路径。

**操作**（新会话）：

```
帮我写一份 长春城市 的资料，500 字
```

等 Commander 完成回复后，发新任务触发闭环沉淀：

```
这个完成了，帮我写一份 哈尔滨城市 的资料，500 字
```

**然后打开「认知 → 待我处理」**，找到新出现的候选：

- [ ] 候选内容可读（判断文本 = 该任务的 lesson，无英文/无模板前缀）
- [ ] 点「确认并限域」→ 选作用范围（如"通用"）→ 确认
- [ ] 候选消失，出现在「我的资产」

**后台确认**（我查）：
```
- 候选池：1 条 confirmed（无 superseded 双写）
- 资产：maturity=seed，lifecycleStatus=system_precipitated_unverified
- 若你确认了：sourceCandidateIds / appliedReviewDecisionIds 有记录
```

## 场景 2：同类任务复用 + 自动升档（5 分钟）

**目的**：验证「注入 → 回执 → 终态证明 → 升档」自动链路。

**操作**：继续发同类资料任务（**不用做任何确认**）：

```
帮我写一份 沈阳城市 的资料，500 字
（等完成）帮我写一份 大连城市 的资料，500 字
```

**观察**：
- [ ] 任务回复里「引用资产」能看到场景 1 沉淀的经验（注入生效）
- [ ] 打开「认知 → 我的资产」→ 找到场景 1 的资产 → 成熟度显示 **已迁移验证**（transfer_validated）

**后台确认**（我查）：
```
- 每次任务：receipt（turn-<id>）+ 终态 proof succeeded + receiptId
- 资产 maturity：seed → transfer_validated
```

## 场景 3：效果反馈 → 顶档（5 分钟）

**目的**：验证「使用与证明 → 用户反馈 → 效果已验证（顶档）」——这是当前唯一能到顶档的入口。

**操作**：打开「认知 → 使用与证明」：

- [ ] 找到场景 2 产生的证明记录（有"本次迁移"标记）
- [ ] 点评价 → 选 **有用**（positive）
- [ ] 回到「我的资产」→ 该资产成熟度显示 **效果已验证**（effectiveness_validated）

**后台确认**（我查）：
```
- effectiveness-proofs 出现 1 条（outcome=better）
- 资产 maturity：transfer_validated → effectiveness_validated
```
