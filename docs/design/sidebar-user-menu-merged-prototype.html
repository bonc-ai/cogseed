主内容区（占位）

方案概览 融合 v2

  • 左下角只保留 一条用户状态栏，原独立「设置」按钮并入其展开面板。
  • 鼠标悬停状态栏 → 面板向上展开，未登录 / 已登录 / Hub 不可用三种状态行为一致；面板与状态栏无缝衔接（重叠 6px），移动鼠标不闪断。
  • 单击状态栏 = 钉住面板（再点收起）；登录动作放进面板内（顶部开关可切换「未登录单击 = 直接登录」）。

交互规格

  • 展开：hover 进入 150ms 后弹出（防路过误触）；focus / Enter 同样展开。
  • 收起：离开「状态栏 + 面板」整体 220ms 后收起，期间回移则取消；已钉住不收起。
  • 键盘：Tab 可在面板项间移动，Esc 关闭；会话列表滚动时自动关闭。
  • 无障碍：复用 aria-haspopup / aria-expanded 语义。

可行性结论

  • ✓ 完全可行：现有账号 chip 已具备「向上弹出菜单」的全部基建（定位、动画、z-index 120、外部点击/Esc 关闭），只需扩面板内容 + 换 hover 触发。
  • 必须处理：Hub 服务不可用时状态栏仍要保留「设置」入口（右下角第三种状态可看降级形态）。
  • 设置项的 active 高亮与红点提示迁移到面板项上。

改动范围（实现时）

  • index.html：移除独立 #settings-btn。
  • account-chip.js：hover/pin/降级三态 + 设置项并入菜单。
  • style.css：面板样式 + 状态栏 active/红点迁移。
  • state.js / boot.js：设置视图入口与高亮指向新结构。
  • 新增少量 locale 文案（帮助/反馈等）。
