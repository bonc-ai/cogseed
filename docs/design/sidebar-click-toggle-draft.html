交互模型 v2 点击切换

  • 去掉：hover 展开（150ms 延迟）、hover 收起（220ms 延迟）、以及随之而来的「钉住」概念（不再需要 pin 图标）。
  • 改为：单击入口 = 展开，再单击 = 收起。展开后保持打开，直到显式关闭——不会被鼠标移动影响。
  • hover 只保留入口的视觉高亮（浅绿底），不再触发任何开合。

关闭面板的四种方式

  • ① 再次单击入口（最常用，与打开对称）。
  • ② 面板底部「收起面板」按钮（可在控制条开关，看效果）。
  • ③ 点击面板之外的区域。
  • ④ 按 Esc（关闭后焦点回到入口）。

「收起面板」按钮定位

  • 不再承担「取消钉住」职责（钉住概念已移除），只等于「再次点击入口」，是纯辅助提示。
  • 保留在面板底部整条、品牌绿高亮，为不熟悉「再点一下收起」的用户留一条显式路径。
  • 若嫌冗余可整体去掉——用控制条「显示收起按钮」开关对比感受。

其它规格

  • 三种账号状态（已登录 / 未登录 / 服务不可用）行为一致。
  • 点击面板内菜单项（设置 / 账号概览…）= 执行动作并关闭面板。
  • 键盘：Enter/Space 在入口上切换展开；Tab 在面板项间移动。
  • 无障碍：沿用 aria-haspopup + aria-expanded，展开时 chevron 翻转朝上。
  • 登录中（signing-in）入口禁用，行为不变。

实现改动范围（确认后）
