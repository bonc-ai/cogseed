本次新增 钉住 + 收起

  • ✓ 已有：hover 展开 / 单击入口钉住（入口出现 pin 图标）——当前代码已实现。
  • ✓ 新增：钉住后面板底部出现一整条「收起面板」按钮（⌄ 图标 + 文案），点击 = 取消钉住并立即收起。
  • 三种状态（已登录 / 未登录 / 服务不可用）钉住后都有收起按钮，行为一致。

收起按钮设计决策

  • 位置：面板最底部、分隔线之下，整条居中——离入口最近，视觉上「从哪来、回哪去」。
  • 仅钉住时渲染，不占用未钉住（hover 临时展开）时的高度。
  • 图标 chevron-down 呼应入口的 chevron；钉住态呈品牌绿，hover 加深。
  • 备选方案 B：面板右上角小图标按钮——省空间但可发现性弱，不推荐。

交互规格（保持不变的部分）

  • 展开：hover 进入 150ms；收起：离开整体 220ms，钉住期间不收起。
  • 点「收起」= 立即取消钉住 + 收起；与 Esc / 点击外部 / 再点入口同效果。
  • 键盘：收起按钮是普通菜单项，Tab 可达、Enter 触发。
  • 无障碍：沿用 role="menu/menuitem" + aria-expanded。

实现改动范围（确认后）

  • locales：新增 hub.chip.menu.collapse（zh/en/ja/pt），zh 文案「收起面板」。
