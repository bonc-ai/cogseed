# 飞书个人上下文 MVP 端到端验收清单

**日期：** 2026-08-10
**前置：** 真实飞书应用就绪（自建应用 + 对外共享 + 个人实名认证 + 日历/云空间/文档只读权限已申请通过），
appId/appSecret 已配置到「设置 → 消息平台」的飞书机器人实例。
**方式：** 按序执行，每步记录实际结果与截图；任一步失败即停，修复后从失败步重跑。

---

## 前置检查

- [ ] 飞书应用已创建并开启「机器人」+「网页应用」能力
- [ ] 应用已开启「对外共享」（外部群/外部用户单聊），完成个人实名认证
- [ ] 只读权限已申请并通过：日历（`calendar:calendar`、`calendar:calendar.event`）、云空间（`drive:drive`、`drive:file`）、知识库（`wiki:wiki`）
- [ ] 重定向 URL 规则已确认：飞书是否允许 `http://127.0.0.1:<动态端口>`（若不支持 → 固定端口方案，改 `callback-server.ts` 一处 + 应用配置写死）

## 阶段 A：身份绑定与 OAuth 授权（10 分钟）

- [ ] 1. 设置 → 消息平台：飞书机器人已绑定（QR 或凭据），状态 connected
- [ ] 2. 设置 → 个人上下文连接器：显示「未连接」
- [ ] 3. 点击「连接飞书」→ 系统浏览器打开飞书授权页，应用内显示「授权中」
- [ ] 4. 授权页勾选范围后确认 → 浏览器显示「授权完成，请返回应用」
- [ ] 5. 应用内状态变为「已连接」
- [ ] 6. 取消路径：重新发起连接 → 点击「取消授权」→ 状态回到「未连接」，无残留授权窗口
- [ ] 7. 并发路径：快速连点两次「连接飞书」→ 无端口泄漏（仅一个授权窗口）
- [ ] 8. 凭据落盘：`<uid>/local/config/personal-context/feishu.json` 存在且为加密载荷（无明文 token）；云目录无凭据

## 阶段 B：资源选择与同步（15 分钟）

- [ ] 9. 已连接状态下「发现资源」：列出主日历/文件夹/文档（只读元数据，无内容）
- [ ] 10. 勾选主日历 + 一个课程文件夹 → 保存 → `cloud/context/scope-manifest.json` 记录选择
- [ ] 11. 首次同步触发：近 30 天事件 + 未来 90 天日历回填，`registry.json` 出现资源条目
- [ ] 12. 增量同步：飞书侧新建一个事件 → 手动触发同步 → 注册表出现新条目，游标推进
- [ ] 13. 幂等：同一事件重复投递/重复同步 → 注册表无重复，候选池无重复候选

## 阶段 C：候选确认闭环（10 分钟）

- [ ] 14. 同步完成后候选入池：飞书主页会话收到「待确认：个人本体候选」卡片（日历事件 → 事件候选）
- [ ] 15. 点击「确认」→ 卡片变 ✅ 终态（不可再点）→ 候选进入本体（USER.md 可见）
- [ ] 16. 另一条候选点「拒绝」→ 卡片变 ❌ 终态 → 候选池移除、本体无该条
- [ ] 17. 新会话提问"我最近有什么安排"→ 只召回已确认事实，未确认候选不出现

## 阶段 D：简报推送（10 分钟）

- [ ] 18. 配置每日简报任务（auto_tasks，默认 8:00，绑定飞书主页会话 + 归属人）
- [ ] 19. 手动触发简报 → 飞书主页会话收到简报（今日日程 + 近期截止 + 空闲时段建议）
- [ ] 20. 简报只含已确认本体事实；未确认候选只提示数量
- [ ] 21. 降级：临时断开数据源 → 简报降级为通用简报，不报错不阻塞
- [ ] 22. 重复触发：同日多次触发 → 幂等键 `briefing:taskId:日期` 生效，不重复推送

## 阶段 E：命令与治理（10 分钟）

- [ ] 23. 飞书私聊 `/权限` → 展示连接状态/已接入资源数/待审批候选数
- [ ] 24. `/遗忘 calendar:主日历` → 先预览影响范围 → 确认后资源失效、派生候选移除
- [ ] 25. 撤销授权 → 同步停止、注册表资源标记失效（来源失效）、凭据清除
- [ ] 26. 重新授权 → 状态恢复 connected，历史失效资源可重新同步

## 阶段 F：健壮性抽查

- [ ] 27. 授权回调超时（5 分钟不完成）→ 状态收敛回「未连接」，可重新发起
- [ ] 28. 网络断开时同步 → 失败但游标不推进，恢复后从原水位续跑
- [ ] 29. 应用重启 → 已连接状态恢复（凭据可解密），同步调度器继续
- [ ] 30. 日志无令牌明文（grep access_token 不出现在日志/账本/工作空间）

---

## 验收判定

- A–E 全过（1–26）→ MVP 闭环可用，可提 MR / 试点
- F 中 27–30 任一项不过 → 记录为已知限制，进加固队列，不阻塞闭环判定
