## 💻 代码质量对比

### V1 旧版代码片段

```javascript
// 状态散落在 DOM 中
const statusText = document.querySelector('.status');
statusText.textContent = '已连接';

// 渲染逻辑混杂
function updateUI() {
  let html = '<div>';
  if (connected) {
    html += '<button>授权</button>';
  } else {
    html += '<button>连接</button>';
  }
  html += '</div>';
  container.innerHTML = html;
}

// 事件处理混乱
button.addEventListener('click', async () => {
  try {
    const result = await invoke('...');
    updateUI();
    showMessage('成功');
  } catch (err) {
    alert(err.message);
  }
});
```

**问题：**
❌ 状态分散
❌ 字符串拼接 HTML
❌ 事件处理和业务逻辑混在一起
❌ 错误处理不统一

---

### V2 新版代码片段

```javascript
// 集中式状态管理
const state = {
  connection: { status: 'connected' },
  // ...
};

function updateState(partial) {
  Object.assign(state, partial);
  notifySubscribers();
}

// 声明式视图渲染
function renderConnectionCard(state) {
  const isConnected = state.connection.status === 'connected';
  return `
    <div class="tp-main-card">
      ${isConnected ? renderAuthorized() : renderConnectButton()}
    </div>
  `;
}

// 统一的事件处理
async function handleConnect() {
  try {
    setLoading(true);
    const result = await invoke('messaging:start-feishu-registration');
    await refresh();
    showNotice('success', '连接成功！');
  } catch (err) {
    showNotice('error', `连接失败：${err.message}`);
  } finally {
    setLoading(false);
  }
}
```

**优势：**
✅ 单一状态源
✅ 声明式渲染
✅ 职责分离
✅ 统一的错误处理
