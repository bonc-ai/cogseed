## 第 11 课 · git 的对象模型

**先决知识**：无（可以随时插入）

**目标**：这是你目前投入产出比最高的一课。

**动手**：
```bash
cat .git/refs/heads/develop        # branch 就是一行 hash
git cat-file -p HEAD               # commit 对象
git cat-file -p HEAD^{tree}        # tree 对象
git log --graph --oneline -20      # DAG
```

**对应 commit**：`e11e22c5`（读 body 里那段 revert 陷阱的诊断）

**该回答的问题**：
1. branch 到底是什么？
2. commit 对象里有哪些字段？
3. `git revert` 一个 merge，撤销的是什么？没撤销的是什么？
4. 为什么 revert 之后再 merge 会显示 "Already up to date"？

**小实验**（**一定要做**）：在一个临时仓库里亲手复现：
```bash
mkdir /tmp/git-test && cd /tmp/git-test && git init
echo a > a.txt && git add . && git commit -m A
git checkout -b feature && echo b > b.txt && git add . && git commit -m B
git checkout main && git merge feature -m M
git revert -m 1 HEAD                # revert 那个 merge
git merge feature                   # 观察：Already up to date，b.txt 不会回来
```

**学完标准**：能向别人解释这个陷阱，并说出三种正确的处理方式。

## 路线 C · 以后不依赖 AI，我自己能修改同类功能

**这条路线不从「变量、循环、数组」开始。**
从你真实项目里缺的那几块开始。

### 阶段 1 · 补掉五个高频空洞（2 天）

按 [05](05-我做过但没有真正学会的东西.md) 的优先级表：

| 顺序 | 补什么 | 用时 | 为什么先补它 |
|---|---|---|---|
| 1 | git 底层数据模型（E1） | 半天 | 你已经踩过，且成本最低 |
| 2 | TS 穷尽性检查（B2） | 1 小时 | 改变你对 TS 的认知 |
| 3 | JS 事件循环（E2） | 2 小时 | 解释经历 1 的修法 |
| 4 | Electron 进程模型（C1） | 2 小时 | 解释你天天用的 invoke |
| 5 | 状态机建模（C3） | 半天 | 你的核心领域 |

**做完这五项**，你回头读自己的代码时，
从「这是 AI 写的」变成「这我懂」。

### 阶段 2 · 补掉实现能力（2 周）

| 顺序 | 补什么 | 怎么练 |
|---|---|---|
| 1 | E2E 测试搭建（B4） | 照着 `cognition-asset-runtime-chain.test.ts` **自己重写一遍** |
| 2 | 数据迁移工程（B3） | 照着 `1eb0b6d0` 写一个假的迁移任务 |
| 3 | 架构门禁实现（B5） | 自己写一条新门禁 |
| 4 | 正则表达式（E3） | 2 小时专项 |
| 5 | 时间复杂度（E4） | 2 小时专项 |

**关键练法**：**不要看着 AI 写的代码理解，要合上它自己重写一遍。**
写不出来的地方，就是你真正不会的地方。

### 阶段 3 · 独立完成一次同类修改（1 周）

**目标任务**（从你的领域里挑一个真实的小需求）：

> 给认知资产加一个新的治理动作，比如「标记为过时（deprecate）」。

**要求你独立完成**：
1. 在 `asset-service.ts` 加状态与迁移
2. 在 `formal-assets/policy.ts` 里决定它的 use policy
3. 加 IPC 通道（`recall.assets.deprecate`）
4. 渲染层加按钮 + 四语文案
5. 写单元测试 + 一条契约测试
6. 检查有没有制造假闭环（谁会消费这个状态？）

**验收标准**：全程不问 AI「怎么写」，只查文档和已有代码。
卡住时允许问「这个概念是什么」，不允许问「帮我写」。

**做完这一步，你就完成了从「判断者」到「实现者」的转变。**

# 第三部分：学习时的三条纪律

### 纪律 1 · 每次只学一课，不要连着学

这套材料是按「一天学一小块」设计的。连着学会让你产生「都懂了」的错觉。

### 纪律 2 · 答不出末尾那 5 个问题就别往下走

那 5 个问题不是复习题，**是这一课的学习目标本身**。

### 纪律 3 · 分清「看懂了」和「学会了」

- **看懂了** = 读 AI 的解释，觉得有道理
- **学会了** = 合上所有材料，能自己讲出来，且能写出来

判断方法见 [13 · 给未来的我](13-给未来的我-如何读这套档案.md)。
