## P12 · 主体错乱：自称"Orkas 平台的指挥官"

- **现象**：问"你是谁"时，Agent 自称"Orkas 平台的指挥官"
- **影响**：若产品层不希望突出底层平台品牌，会造成主体错乱
- **期望方案**：统一身份策略——产品品牌 / Agent 名称 / 平台底座三层分开；普通用户默认只看到当前产品或 Agent 身份（平台底座不暴露）
- **验收点**：默认身份不暴露底层平台品牌；三层身份策略明确
- **状态**：已完成（2026-08-11）——prompt 身份规则 + 工具消息/CLI 注入中性化 + UI 文案（四语 locales 20 处 "Orkas" → 中性"应用"表述）；遗留：用户历史记忆里的旧品牌内容清理（非代码）
