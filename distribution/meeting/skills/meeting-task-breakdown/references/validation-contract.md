# 验证契约

交付前核对：完整性、实际来源、否定与条件、数字与日期、人工补充、模型建议、版本关联和未确定字段。不得伪造外部任务标识、归档路径、审计引用或已确认状态。

边界案例见 eval-cases.yaml 和 evals/evals.json，要求均是待模型评估的验收判据，不是已通过的运行结果。

HITL：本 Skill 无写动作，返回待审草稿。用户对归档已有明确授权时 Agent 可按已授权范围新增归档；不得覆盖原文。实际外部写入必须由 Agent 执行“预览 → 用户确认具体预览 → 执行”，纪要确认与任务清单确认不能替代外部创建确认。新内容、账号或范围变化后重新确认。

转写和纪要由 Agent 保存成文件并登记产物，应用在任务 completed 后自动归档。等待自动归档或索引不阻塞候选任务拆分与用户确认。本 Skill 不能代写知识库目录或以生成 Markdown 宣称入库成功。

## 第二段闸口验收

未确认纪要不拆分，修改后的新纪要需重新确认，确认后仍须独立选择拆分；拒绝拆分不应调用本技能且整个纪要整理正常完成。只有明确选择才输出任务；只保留清单不查询或写外部系统，缺字段仅为待确认。外部创建仍须另有具体预览确认；精简正文不删任务完成条件及必要预览。
