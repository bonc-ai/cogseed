PH

PageHeader

标题、数量和页面操作保持在同一行；不提供副标题插槽，所有操作统一为 secondary / sm。

BTN

Button

4 个角色 × 2 个尺寸 × 6 个可核对状态，不暴露 padding、字号或圆角。

IB

IconButton

图标来自统一图标集；缺少 accessible name 时组件直接拒绝渲染。

FRM

Input · Select · Form

所有 Select 统一使用原项目 AiSelect；同一套行为覆盖简单选项、说明、图标与弹窗浮层。

采用策略 原生 Input / Textarea：兼容 .form-input 所有 Select：统一使用现有 AiSelect 简单场景只传 label/value；复杂场景按需增加 hint/icon
Input / Textarea默认 · 悬停 · 焦点 · 禁用 · 只读 · 错误
Select / AiSelect默认 · 焦点 · 禁用 · 错误 · 带说明
复合 Form字段语义、两列布局、局部错误与统一操作区
EMP

EmptyState

A 安静告知、B 解释原因、C 引导行动；C 型只能有一个主要操作。

MOD

Modal

点击打开真实组件。请实际检查 ESC、Tab/Shift+Tab、滚动锁定、焦点返回与 Cmd/Ctrl+K。

ESC 关闭焦点圈定关闭后返回背景锁定内层浮层先关Cmd+K 位于弹窗上方
AUTO

自动化页面组合态

组件不是孤立样式。这里用同一套组件核对列表、加载、空、失败四种页面结果。
