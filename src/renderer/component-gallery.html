CHR

WindowChrome

macOS 红绿灯由 Electron 原生绘制；Shell 只管理右侧搜索、运行状态与侧栏收起/展开。

PH

PageHeader

标题、数量和页面操作保持在同一行；不提供副标题插槽，所有操作统一为 secondary / sm。

USR

UserMenu

侧边栏底部保持单行个人身份入口；菜单向上弹出，设置与退出沿用真实图标、焦点和危险色。

PAGE

ResourcePage

工作空间、自动化、认知资产和能力管理共用响应式边距、内容宽度与 Header 后留白；导航按页面需要出现。

TAB

Tabs

下划线导航保持单行滚动；左右方向键与 Home / End 复用真实页面的 roving-focus 约定。

CARD

ResourceCard

工作空间、自动化、智能体、技能与连接共用同一网格和外壳；业务内容、操作和状态仍由各页面负责。

SET

SettingsSection

浅描边、16px 内边距、无阴影；分组间距承担层级，不再由页面叠加卡片效果。

BTN

Button

4 个角色 × 3 个尺寸 × 6 个可核对状态，不暴露 padding、字号或圆角。

IB

IconButton

图标来自统一图标集；缺少 accessible name 时组件直接拒绝渲染。

SEG

SegmentedControl

浅色轨道 + 白色选中片；每项保留原生按钮、Tab 访问和 aria-pressed。

CMP

Composer

首页、已有对话和窄宽共用生产输入台样式；这里只核对视觉与响应式，发送、停止和排队仍由真实页面状态机负责。

FRM

Input · Checkbox · Select · Form

所有 Select 统一使用原项目 AiSelect；同一套行为覆盖简单选项、说明、图标与弹窗浮层。

采用策略 原生 Input / Textarea：兼容 .form-input 所有 Select：统一使用现有 AiSelect 简单场景只传 label/value；复杂场景按需增加 hint/icon
Input / Textarea默认 · 悬停 · 焦点 · 禁用 · 只读 · 错误
Select / AiSelect默认 · 焦点 · 禁用 · 错误 · 带说明
复合 Form字段语义、两列布局、局部错误与统一操作区
SEL

CommandPalette · SearchableSelect · DateRangePicker

共享外观与可访问状态；业务搜索、选择值和自动化调度仍由生产模块负责。

Cmd/Ctrl+K方向键 + EnterEscape 返回焦点IME 组合期忽略动作键窄宽不横溢
CommandPalette默认 · 打开 · 搜索中 · 无结果 · 错误 · 窄宽 · 键盘/IME
SearchableSelect / Select默认 · 打开 · 搜索中 · 无结果 · 禁用 · 错误 · 窄宽
DateRangePicker / Date默认 · 错误 · 窄宽 · 键盘/焦点
EMP

EmptyState

A 安静告知、B 解释原因、C 引导行动；C 型只能有一个主要操作。

MOD

Modal

点击打开真实组件。请实际检查 ESC、Tab/Shift+Tab、滚动锁定、焦点返回与 Cmd/Ctrl+K。

ESC 关闭焦点圈定关闭后返回背景锁定内层浮层先关Cmd+K 位于弹窗上方
AUTO

自动化页面组合态

组件不是孤立样式。这里用同一套组件核对列表、加载、空、失败四种页面结果。
