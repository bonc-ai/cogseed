CogSeed · 工作空间目录架构

空间化重构后：空间会话 → 每空间一个工作区文件夹 · 非空间会话 → 全局 userWorkSpace · CLI agent 例外落根（cwd 稳定保 --resume）

空间会话 → 空间自己的工作区

  • • data/<uid>/cloud/spaces/<sid>/workspace/<会话slug>/
  • • 每个空间一个 workspace 根，空间内每会话一个标题 slug 子目录
  • • slug 首次解析后冻结（state.json::workspace_dir），改标题不搬家
  • • 迁移：解绑/换空间时目录同盘 rename / 跨盘 copy（migrateConversationWorkspace）

非空间会话 → 全局默认

  • • userWorkSpace/<会话slug>/（getWorkspacePath(uid) + slug）
  • • 解析链：项目钉的目录 → 默认选择 → userWorkSpace 兜底
  • • 老会话（无 workspace_dir 记录）仍直接在根下干活（惰性迁移）

CLI agent 例外：一律落 userWorkSpace 根

  • • WorkBuddy / Claude / Codex 的 cwd = userWorkSpace 根（bus.ts CLI 分支）
  • • 刻意保持 cwd 稳定：CLI 会话存档按 cwd 哈希，变了 --resume 就断
  • • 路径沙箱不约束 CLI —— 隔离靠 CLI 自身权限默认值（codebuddy 默认仅 cwd）
  • • 提权手段：--permission-mode bypassPermissions / --add-dir（最小权限推荐）
